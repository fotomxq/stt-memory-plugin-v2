## 0. 一页摘要

**现象**：每个维度列表页（情节 / 记忆 / 状态 / 物品 / 传言 / 计划 / 悬念 / 概念 …）顶部都有一行
「**NSFW 留档：弱 N · 强 M**（按原文判定，弱化后不变；标记见每条末行，与楼层等信息同段）」。
它由 v3.9.0（用户当时要求「均要有标签提示」）引入，渲染函数 `ui/list-rows.js#nsfwLegendHtml(items)`，两处调用点（通用列表分支 + 状态分类分支）。

**为什么它没意义（本稿的判断依据）**：

| # | 理由 |
| --- | --- |
| ① | 它只是**当前筛选结果**的计数（`items` = 已过滤列表）→ 同一个页面在筛选前后给出不同数字，**不构成任何稳定事实** |
| ② | 用户需要的是"**这一条**是什么等级"——那已由**每条末行的等级标签**（`NSFW·弱` / `NSFW·强` + 级别释义 tooltip）承担 |
| ③ | 逐条标签是**行动信息**（决定要不要弱化某条）；汇总计数**不指向任何动作**（页面上没有"按等级筛选"这类以它为前提的操作） |
| ④ | 与同页其它信息（`共 N 条` / `命中 M` / 状态组数）**语义重叠**：都是计数，但后者对应真实操作（筛选 / 分组），前者不对应 |

**主张**：**只去掉统计行，不动留档** —— 判定与补档逻辑、条目字段、逐条标签一律保持；这是"UI 减法"，不是功能下线。

| G3 | 死代码清零：渲染函数与导出**一并删除** | `ui/list-rows.js` 不再导出 `nsfwLegendHtml`；全仓无引用 |

### 1.2 非目标（明确不做）

| # | 不做 | 理由 |
| --- | --- | --- |
| N1 | 删除条目的 NSFW 等级字段或判级逻辑 | 用户要去的只是"统计信息"；注入 / 弱化 / 词条分析仍在用 |

## 2. 现状核对（只读，逐条带证据）

| # | 结论 | 证据 |
| --- | --- | --- |
| ① | 统计行由单一函数产出，两处调用 | `ui/list-rows.js#nsfwLegendHtml` · `ui/panel.js`（通用列表 `return` / 状态分类 `head`） |
| ② | 逐条标签是**另一条**渲染路径（与统计行无关） | `ui/list-rows.js#nsfwBadgeHtml` + `appendBadgeToLastLine`（v3.11.0 起注入末行） |
| ③ | 统计口径 = 传入列表的即时计数（**含筛选影响**） | `nsfwLegendHtml(items)` 内 `for (const it of arr)` 累计 `weak` / `strong` |
| ④ | 该标记已被审计白名单登记（删元素须同步删登记） | `tests/unit/panel-audit.test.js#L5` 的 `'nsfw-legend'` 条目 |
| ⑤ | 冒烟里七类页遍历**同时**断言了统计行与逐条标签 | `tests/smoke-test.js`「逐个分类页」段 |

## 3. 方案

### 3.1 改动面（3 处代码 + 3 处测试）

| 面 | 改动 |
| --- | --- |
| `ui/list-rows.js` | 删 `nsfwLegendHtml`（函数 + 导出）；原位留**说明注释**（写清"删的是统计行、保留的是逐条标签"，避免后人误判为漏改） |
| `ui/panel.js` | 删 import 名 · 删 `const nsfwLegend = …` · 两处调用点（通用列表 `return` 与状态分类 `head`） |
| `tests/smoke-test.js` | 七类页遍历断言由「**存在** `data-ftt-nsfw-legend`」**反转**为「**不存在**」（同时仍要求等级标签在位） |
| `tests/unit/nsfw-level.test.js` | `F1b` 重写为同款反向锁（条目本体仍渲染标签、面板渲染不含汇总行）；清理导入 |
| `tests/unit/panel-audit.test.js` | `L5` 白名单删除 `nsfw-legend` 条目 |

### 3.2 判定口径（"该删" vs "该留"）

| 元素 | 判定 | 依据 |
| --- | --- | --- |
| 分类页顶部汇总行 | **删** | 过滤结果的计数，不指向动作（§0 ①②③④） |
| 每条末行等级标签 | **留** | 逐条行动信息；留档本身 |
| 设定页状态行 + 「🔖 立即补档」 | **留** | 功能自述与唯一补档入口（`N2`） |
| `nsfw` 字段 / 判级 / 自动补档 | **留** | 注入、弱化、词条分析的数据源（`N1`） |
