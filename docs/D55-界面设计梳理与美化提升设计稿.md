## 0. 一页摘要

当前插件界面在近期迭代中局部引入了现代化的卡片、汇总条与结构化表单（如 `ui/money-tabs.js` 的货币三子页、`.ftt-editor` 表单美化、`ui/fields.js#nodeTableHtml` 的结构化节点表、`ui/scene-map-graph.js` 的网状图 SVG），但其余面板分页、设定子页与样式表仍停留在早期平铺形态，导致**跨页面视觉割裂、信息层级扁平、长列表与长表单阅读负担重、样式令牌存在重复与未定义引用**。

本稿对全站 13 个面板分页、15 个设定子页及 `style.css` 进行系统梳理，提炼出 **6 个核心美化提升域**，并形成 **8 条可实施、可验收、可回退的设计要求**：

| 域 | 现状痛点（只读取证） | 提升与美化目标 | 对应条目 |
| --- | --- | --- | --- |
| **① 视觉标准与令牌体系** | `style.css` 存在两套 `#ftt-panel` 令牌块；地图与行多选引用了未定义的 `--ftt-fg*` / `--ftt-err`；局部仍散落硬编码色值 | 建立全站视觉层级准则（`业-14`）；合并单一令牌源、修复未定义变量并补门禁（`技-60`） | `业-14` · `技-60` |
| **② 总览页仪表盘化** | `ui/panel.js#overviewBody` 各区块以虚线平铺；工具行未按 `docs/D23` 的 B/C/D/E 分区形成视觉分组；类目统计胶囊挤在一行 | 时钟与在场升级为状态卡；工具栏按「主动作 + 分区胶囊组」编排；管线带进度条；类目统计改响应式网格卡片 | `应-48` |

## 1. 目标 / 非目标

### 1.1 目标

1. **确立全站视觉层级与信息密度标准**：将货币三子页已验证的「顶部汇总胶囊 + 结构化行卡片 + 分区详情 + 结构化子表」确立为全站统一视觉基准（§3.1，`业-14`）；
2. **收敛 CSS 设计令牌并消除未定义变量**：合并 `style.css` 重复的 `#ftt-panel` 变量块，修正 `--ftt-fg*` / `--ftt-err` 等未定义变量引用，将残余硬编码色值收敛至 `--ftt-*` 令牌并纳入 `scripts/check-ui-spec.js` 机械检查（§3.2，`技-60`）；
3. **升级总览页为结构化仪表盘**：重塑剧情时钟卡、分区工具栏、管线进度条与类目统计网格，消除平铺虚线感（§3.3，`应-48`）；
4. **统一多级导航与子标签交互形态**：收敛 5 处子标签条为统一组件，并为设定页 15 个子页提供四分组聚类视图（§3.4，`应-49`）；
5. **提升列表行、状态分组与场景树的卡片层级**：明确行内「首行标题与徽标 · 中段正文 · 末行浅色元信息」三段式排版，支持状态页角色组折叠与场景树层级线（§3.5，`应-50`）；
6. **统一 AI 方案预览与编辑表单体验**：建立公共预览对比卡片组件与长表单分组/结构化输入机制，同时通过模块外提严守单体文件体量棘轮（§3.6 / §3.7，`应-51` · `应-52` · `技-61`）。

### 1.2 非目标（明确不做）

- **N1 不改任何代码 / 不动版本号 / 不打 tag**：本轮属设计轮次（`开发守则.md` §1）；
- **N2 不引入前端框架、CSS 预处理器或构建步骤**：仓库保持无构建形态（源码即发布物，`docs/D9` §1 N1）；
- **N3 不改任何业务数据契约与存储结构**：所有美化与重构仅作用于 `ui/` 渲染层与 `style.css`，不改 `DATA_VERSION`、不改归一函数与跨端哈希；
- **N4 不改既有 `data-ftt-action` 动作名与测试钩子属性**：保持 `tests/unit/panel-audit.test.js`、`tests/unit/ui-wording.test.js` 等既有门禁契约兼容；
- **N5 不强行将复杂关系网格改为卡片**：`ui/rel-table.js` 的 7 列可编辑关系网格已登记为 `docs/D9` U11 真表格唯一例外，本稿保持其表格形态，仅对齐控件边框与焦点令牌。

## 3. 方案

### 3.1 业务与体验基准：全站界面视觉层级四原则（`业-14`）

在不改变业务数据语义的前提下，将用户在货币三子页与长期收支编辑器中认可的设计范式提炼为全站适用的四条视觉基准（回写 `docs/01-业务架构.md` 与 `docs/D9-UI统一规范设计稿.md`）：

1. **先汇总后明细**：每个主分页顶部提供结构化汇总胶囊栏（核心计数 / 状态分布 / 容量或窗口读数），先给全局体感再进明细列表；
2. **三段式条目卡片**：每条列表记录严格分为「首行：主标题 + 语义徽标」「中段：高可读性正文（控制行宽与行高）」「底栏：弱化的时间 / 楼层 / 调用次数 / 重要度元信息」，不同层级不混排；
3. **预览必见前后对比**：所有不直接落库、需用户确认的修复/融合/联动方案，必须以结构化对比卡呈现「操作类型 + 变更前 → 变更后 + 依据/原因」，不以纯文本换行堆砌；
4. **长表单必分组、多值必结构化**：字段数 > 8 的编辑表单按业务语义分节（支持折叠次要分节）；多列复合字段（如节点记录、目标可能性）优先采用行表控件而非手填分隔符文本。

### 3.2 设计令牌（Design Tokens）统一与样式表清理（`技-60`）

1. **合并 `#ftt-panel` 令牌声明**：将 `style.css` 首块旧变量（`--ftt-panel-bg`、`--ftt-panel-head-bg`、`--ftt-border`、`--ftt-border-strong`）统一定义为 v2 核心令牌（`--ftt-bg-1`、`--ftt-bg-2`、`--ftt-line`、`--ftt-line-strong`）的语义别名，消除双源维护。
2. **修复未定义变量并补齐色板令牌**：
   - 将 `.ftt-map-*` 与 `.ftt-selmark` 中的 `--ftt-fg` / `--ftt-fg-2` / `--ftt-fg-3` / `--ftt-err` 全部替换为已定义的 `--ftt-text-1` / `--ftt-text-2` / `--ftt-text-3` / `--ftt-danger`；
   - 新增语义软底色与边框令牌：`--ftt-ok-border`、`--ftt-warn-border`、`--ftt-danger-border`、`--ftt-info-soft`、`--ftt-info-border`，将 `.ftt-money-in`、`.ftt-money-out`、`.ftt-chip-ok`、`.ftt-chip-warn`、`.ftt-forecast` 等规则全部收敛至令牌。
3. **升级 `scripts/check-ui-spec.js` 门禁（C9 扩展）**：增加「`style.css` 中引用的所有 `var(--ftt-*)` 必须在 `#ftt-panel` 根块有定义」的静态断言（零未定义令牌）。

### 3.3 总览页仪表盘（Dashboard）视觉重构（`应-48`）

将总览页渲染逻辑从 `ui/panel.js#overviewBody` 抽入新模块 `ui/overview.js（拟建）`，在不改变任何按钮 `id` 与 `data-ftt-action` 的前提下升级为四区仪表盘：

| 区块 | 现状 | 美化提升方案 |
| --- | --- | --- |
| **① 剧情时钟与在场卡**（`ui/clock.js#clockSectionHtml`） | 四行 `.ftt-clock-line` 垂直堆叠，与下方工具行混同 | 升级为 `.ftt-clock-card` 双栏/响应式网格：左侧突出显示「📅 当前剧情日期 + ⏱ 时间 + 🔒 锁定态」，右侧显示「📍 当前地点 + 👥 在场角色胶囊」；手工改写按钮与自动同步状态内嵌在卡片底栏 |
| **② 核心工具栏分区**（遵循 `docs/D23` §3.2） | 6 个按钮平铺在单行 `.ftt-row` | 按 `D23` 的 B/C/D/E 分区渲染为带浅色分组框的 `.ftt-toolbar-group`：**主操作区**（⚡ 立即 AI 摘要 + 📤 立即注入）突出显示；**维护区**（🛠 自动修复 · 🧭 推演世界 · 🌶 弱化 NSFW）与**存取区**（💾 保存 · ⬇ 导出 · ⬆ 导入）分组成簇 |
| **③ 管线状态与注入健康度**（`ui/panel.js#pipelineBoxRowsHtml`） | 纯文本行拼装 | 管线在途时展示动态细进度条（`.ftt-pipe-bar`）与分段读秒；注入概览与「最后一次提取」合并为紧凑的「运行摘要双卡」，折叠块「查看注入内容」保持按需展开 |
| **④ 类目统计与未摘要楼层** | 12 个 `.ftt-chip` 单行折行；未摘要楼层按钮平铺 | 类目统计改为自适应网格卡片 `.ftt-stat-grid`（每格显示「图标 + 类目名 + 醒目数字」，非零项高亮，点击直跳对应分页）；未摘要楼层区头部显示覆盖率进度条与「一键批量 / 单楼点选」清晰引导 |

### 3.4 顶栏导航、页内子标签与设定页分组导航美化（`应-49`）

1. **主标签栏（`ui/panel.js#PANEL_TABS`）增强**：
   - 为 `.ftt-tabs` 增加左右横向滚动阴影指示（CSS `background-attachment: local, local, scroll, scroll`），解决窄屏下看不出右侧还有标签的问题；
   - 选中态 `.ftt-tab.ftt-on` 增加底部强调色亮条（`box-shadow: inset 0 -2px 0 var(--ftt-accent)`）与微抬升背景，提升当前所在页辨识度。
2. **统一页内子标签组件（`ui/subtabs.js（拟建）`）**：
   - 将 `atomsBody`、`moneyPageHtml`、`sceneMapTabsHtml`、`constraintPageHtml` 四处页内子标签统一收敛为分段胶囊条（`.ftt-segmented`）：浅底色圆角槽 + 选中项实心高亮胶囊 + 计数角标 `.ftt-subtab-cnt`，保留全部既有 `data-ftt-*` 属性。
3. **设定页 15 子页分组聚类（`ui/settings-pages.js#settingsSubTabsHtml`）**：
   - `SETTINGS_TABS` 的 15 个子页保持 `id` 与顺序不变，但在导航渲染层按 4 个语义簇分组展示（带轻量组标题标签）：
     - **核心与连接**：基础 · API与模型 · 提示词
