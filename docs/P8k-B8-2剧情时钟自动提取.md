## 2. 与 V1 的偏差（逐条明示）

1. **取文经注入钩子**：V1 在函数内直接调 `latestAiFloorText()` 与 `collectFloorLinesInRange(...)`；V2 由宿主经
   `setClockTextHooks({ latestAiText, floorWindowText })` 注入（`index.js` 用 `host/chat.js#latestAiMessageText` 与
   `host/floors.js#collectFloorLinesInRange` 接线），内核保持零宿主依赖。
2. **提示与调度**：V1 在函数内 `notify(...)`/`renderPanel()`/`setTimeout(...)`；V2 提示走 `notifyHooks`、延迟走 `timerHooks`、
   面板重绘由 UI 层负责（与 B8-1 同一口径）。
3. **`clockRepair` / `clockRegexGen` 两条 AI 管线**仍属后续批次（**B8-3**）：基础页对这两项以「属后续批次」明示标注，不放假按钮。
4. **`cfg.clockExtractEnabled` 的 force 通道**：`clockAutoExtractOnce({ force: true })` 供测试与手动调用绕过总开关（V1 无此参数；
   等价于 V1 手动路径的效果），默认路径完全按 V1 的开关判定。
