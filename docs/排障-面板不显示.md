# 排障 · 安装后看不到面板

> 文档版本：v1.0 ｜ 日期：2026-09-24 ｜ 状态：生效
> 适用版本：v2.0.1 起（v2.0.0 存在本页首条问题）
> 相关：`index.js`（装配与探针）、`ui/settings-panel.js`（容器候选）、`ui/menu.js`（魔杖菜单入口）

---

## 1. 面板在哪儿（先确认这一点）

FTT 面板挂在**扩展设置抽屉**里，不是顶栏、也不是魔杖菜单：

1. 左侧栏 → **扩展（Extensions）** 按钮（或顶栏扩展图标）；
2. 抽屉内找到 **「FTT记忆组件 V2」** 标题行 —— 这是一条**可点开的折叠抽屉**（默认收起）；
3. 点击标题展开，即可看到「基础开关 / 记忆与注入 / 状态与动作 / 数据台 / 更新」各区块。

> TauriTavern 等原生移植里，扩展抽屉的入口与分组可能与 Web 版略有差异；
> 若抽屉里确实没有「FTT记忆组件 V2」，按 §2 自查。

## 2. 三步自查（v2.0.1 起）

在聊天输入框里依次执行：

| 命令 | 看什么 |
| --- | --- |
| `/ftt` | 首行是否显示「装配：已初始化」；是否列出「触发 load→…」；「面板 已挂载 #<容器>」还是「未挂载：<原因>」 |
| `/ftt-panel` | 强制重新挂载一次，并报告：面板容器候选命中情况（`extensions_settings2✓ / extensions_settings✗ / rm_extensions_block✗`）、菜单入口状态、以及面板位置提示 |
| `/ftt-analyze list` | 顺带确认提取链路是否可读（楼层清单） |

浏览器控制台（`F12` → Console）还可直接调用：

```js
FTT.panelInfo()      // { ok, via, container, reason, found:{...}, mounted, candidates:[...] }
FTT.menuInfo()       // { menuId, menuFound, installed, candidates, mount:{...} }
FTT.forceMount()     // 强制挂载（返回同上诊断）
FTT.snapshot()       // 版本 / 宿主 / 探测 / 绑定 / 拦截器 / 存储 / 提取 全量状态
```

## 3. 常见原因与处理

| 现象（`/ftt-panel` 输出） | 原因 | 处理 |
| --- | --- | --- |
| 面板 `未挂载：未找到扩展设置容器（候选：extensions_settings2 / extensions_settings / rm_extensions_block）` | 该宿主的扩展设置区块 id 与三者都不同 | 把 `/ftt-panel` 的输出发给我；同时可先用魔杖菜单入口（§4）打开面板 |
| 面板已挂载，但界面看不到 | 扩展设置抽屉未展开，或面板在抽屉底部需滚动 | 展开扩展设置抽屉；面板标题为「FTT记忆组件 V2」 |
| `/ftt` 都不存在（命令未注册） | 插件脚本未加载（多半是安装不完整或 JS 报错） | 看 `F12 → Console` 的红色报错；确认扩展目录里 `index.js`、`manifest.json`、`settings.html` 都在 |
| 版本仍在 `2.0.0` | 未更新到修复版 | 在扩展管理里对本扩展执行 Update（或重新安装），确认 `manifest.json` 版本为 `2.0.1` |

## 4. 兜底入口：魔杖菜单

v2.0.1 起会在扩展魔杖菜单（`#extensionsMenu`）里插入一项 **「FTT记忆组件」**；
点击它会**强制重新挂载面板**并给出结果提示（成功/失败原因）。
即使面板容器 id 与候选列表都不符，这个入口也能让用户看到插件是否在工作。

## 5. 设计上的防复发

- 装配**不再依赖单一事件**：`APP_READY` / `APP_INITIALIZED` / `DOMContentLoaded` / `window.load` / 有限轮询（20×750ms）/
  命令调用，任一先到即初始化（`ensureReady()` 去重）；
- 已初始化但容器不存在时，探针会**继续只重试挂载**，容器一出现即自动补上；
- 诊断入口在**模块加载期**就注册，因此「出问题时没有任何自查手段」这类二次伤害不会再有；
- 相关回归测试：`tests/unit/bootstrap.test.js`（零事件装配 / 容器回退 / 无容器可诊断自愈 / 无事件源宿主 / 菜单入口 / teardown 恢复）
  与冒烟 L1–L4。
