# P10c170 · AI 分析防失控 + 批量分析优化（v3.52.17）

> 文档版本：v1.0 ｜ 日期：2026-11-18 ｜ 状态：生效（v3.52.17）
> 用户要求（原话）：
>   1.「ai分析行为存在失控行为，可能提交了超长上下文或反复提交行为，请核对修复。」
>   2.「批量分析能力需优化，不要高频次分析，每次分析多个楼层正文，分析后提炼。避免反复提交、提交后没标记重复提交等。」
> 关联：`host/extract.js` · `core/chunk.js` · `core/config.js` · `index.js` · `ui/settings-pages.js`

## 1. 根因（核对结论）

| # | 失控点 | 事实 |
| --- | --- | --- |
| A | **超长上下文无上限** | 分段只按「楼层数」切（`summaryChunkSize`），**没有字符预算**；单楼正文极长时整段直接进提示词（硬上限也没） |
| B | **失败后反复提交** | AI 失败 / 无 JSON / 合并失败时**不记账**，该楼仍留在「未分析」清单 → 下一次自动触发再次提交，可无限循环 |
| C | **高频次触发** | `GENERATION_ENDED` 每次事件都直接跑自动提取（重 roll / 编辑 / 多事件会连续触发），**没有去抖、没有冷却** |
| D | **提交后没标记** | 同 B：失败路径无「已尝试」记录，手动/自动都会重复投递 |

## 2. 修复

### ① 超长上下文（两道闸）

* `core/chunk.js#chunkFloorIdsByChars`：段内再按**累计正文字符数**收口（`cfg.summarySegMaxChars`，默认 8000；
  0 = 不限）。单楼本身超长时仍独占一段。
* `host/extract.js#analyzeSegment`：单段**硬上限** `SUMMARY_SEG_HARD_MAX = 30000` 字 —— 超出截断并写调试日志
  （提交文本带「已截断」标记），**绝不把整段超长正文塞给 AI**。

### ② 反复提交 / 提交后没标记

* `host/extract.js` 新增**失败记账** `state.extractFailures`（有界 ≤200、7 天过期）：
  * 失败路径（`ai-error` / `no-json` / `merge-fail`）逐段记账；**内容哈希变化 → 计数从 1 重算**（改过的楼值得重试）；
  * 连续失败 ≥ `cfg.summaryFailMarkAfter`（默认 3）→ **记为已处理**（`recordProcessedFloors`）并写调试日志 ——
    停止自动重投；手动「清空已处理楼层记录」可重来；
  * 成功 → 清掉该段失败记账。
* 单楼（`analyzeFloor`）与分段（`analyzeSegment`）**同一套**记账口径。

### ③ 高频次分析

* `index.js`：`GENERATION_ENDED` → 自动提取**去抖合并**（1.2s 窗口内多次事件只跑一次）；
* `host/extract.js#autoExtractLatest`：**最小间隔冷却**（`cfg.autoExtractGapMs`，默认 8000ms），间隔内重复触发直接
  `cooldown` 跳过（只作用于自动路径；手动「⚡ 立即 AI 摘要」不受影响）。

### ④ 批量分析不变的部分

* 仍「一段 = 多个楼层正文 = 一次 AI 请求」（`summaryChunkSize` 默认 3）；分析后照旧触发情节总结检查点（提炼）；
* 新增只加**上界**（字符预算 / 硬上限 / 失败阈值 / 冷却），不改提示词模板与落库口径。

## 3. 新增配置（设定 → 分析记忆 → 分析范围）

| 键 | 默认 | 作用 |
| --- | --- | --- |
| `summarySegMaxChars` | 8000 | 每段正文字符预算（0 = 不限） |
| `summaryFailMarkAfter` | 3 | 同段连续失败几次后标记已处理（停止自动重投） |
| `autoExtractGapMs` | 8000 | 自动提取最小间隔（防高频次） |

## 5. 边界（如实登记）

1. **失败标记 ≠ 数据丢弃**：标记后该楼不再自动重投，但正文与已有记忆都在；清台账或内容变化可重试；
2. 单段硬上限截断会**丢该段尾部超长部分**（>30000 字），已写调试日志并在提交文本标注；正常楼层远低于该值；
3. 冷却只作用于**自动**路径；手动分析不受影响（用户显式操作）。
