## 2. 核对发现并修复的两处真缺陷

1. **编辑器记账不联动余额**（`ui/console.js#consoleSave`）：保存 `kind=ledger` 时直接 `upsertEntry` → 只写账本、不动余额/摘要，等于「记了账但钱没变」。
   **修法**：`kind=ledger` 改走 `applyLedgerEntry`（校验货币 → 写账本 → 余额联动 → 摘要刷新 → 幂等），失败返回 `ledger-rejected` 并如实提示。
2. **`ledger` / `deals` 缺编辑器字段表**（`ui/fields.js`）：`kindFields` 无这两个分支 → 编辑器空白。
   **修法**：`ledger` 6 项（货币 ID 必填 / 日期 / 金额 / 说明 / 来源 / 标的物 ID）；`deals` 15 项（名称 / 约定 / 类型 / 锚定货币 / 起止 / 周期 / 现状 / 三段预判）；
   `deconstructEntry('deals', …)` 把扁平表单还原为 `outlook{text, nodes, forecast}`（**预测与事实分字段**）。
