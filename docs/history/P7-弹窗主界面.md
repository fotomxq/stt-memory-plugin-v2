# P7 · 弹窗主界面（对齐 V1 的交互形态）

> 文档版本：v1.0 ｜ 日期：2026-09-24 ｜ 状态：生效（v2.1.0）
> 关联：`ui/popup.js`、`ui/console.js`、`ui/settings-panel.js`、`ui/menu.js`、`ui/floating.js`、`docs/排障-面板不显示.md`

---

## 1. 为什么改（用户实测反馈）

用户反馈两点：

1. 「原先扩展内增加按钮，会弹窗方式处置，**包括访问记忆**」——V1 的交互是**入口按钮 → 弹窗**；
2. 「扩展看到了『FTT记忆组件 V2』卡片，这个设计完全没必要，因为原先 V1 弹窗已经身经百战很好用了」。

结论：V2 此前采用 ST 标准的**内联抽屉卡片**（且数据台塞在卡片里），与 V1 习惯不一致；本版把主界面改为**弹窗 + 分页**，
抽屉卡片改为**可选**（默认关闭）。

## 2. 入口（三处，均为弹窗）

| 入口 | 说明 |
| --- | --- |
| 扩展魔杖菜单「FTT记忆组件」 | **主入口**：点击打开弹窗 |
| `/ftt-ui [overview\|console\|extract\|settings]` | 命令打开弹窗（可指定初始分页） |
| 右下角悬浮「FTT」按钮 | **兜底**：扩展菜单容器不存在时自动出现（点开同一个弹窗） |
| `FTT.ui(tab)` / `FTT.openPanel()` | 控制台调试入口 |

抽屉卡片：仅当 `cfg.uiShowDrawer = true` 时渲染（设置分页里可开）；`/ftt-panel` 仍用于**排障**（报告容器候选命中情况与强制挂载）。

## 3. 弹窗分页

| 分页 | 内容 | 复用模块 |
| --- | --- | --- |
| **总览** | 版本 / 作用域 / 条目合计与逐维计数 / 注入字数与命中审计 / 内核配置键数 / 容器候选 + 快捷动作（分析未分析楼层、刷新、清空注入、检查更新） | `console.js` + `host/inject` |
| **数据台** | 14 维浏览、搜索、查看与编辑（标题·正文·日期·标签·重要度）、删除（双墓碑）、**注入自查** | `ui/console.js` |
| **提取** | 未分析楼层清单 + 逐楼「分析」+「分析全部未分析楼层」+ 运行/成功/失败统计 | `host/floors` + `host/extract`（经钩子注入） |
| **设置** | 内核配置（注入开关·预算·条数上限·自动提取·14 维启用）、更新检查、V1 导入（干跑/写入）、诊断行 | `ui/settings-panel.js`（表单与绑定复用） |

## 4. 渲染与动作的分离（可测性）

```text
popupHtml(tab)              → 弹窗外壳 HTML（分页条 + 内容区 + 提示行）
popupBodyHtml(tab)          → 单页内容 HTML
popupAction(action, payload)→ 唯一动作入口：
    tab / refresh / analyze-all / analyze-floor / clear-inject / check-update / console
writePopupBody()            → 真实 DOM 用 innerHTML 替换；桩 DOM 追加
bindPopup()                 → 真实 DOM 按 [data-ftt-tab] / [data-ftt-pop] 接线；无 querySelectorAll 时跳过
```

弹窗宿主走 ST 的 `callGenericPopup(html, POPUP_TYPE.TEXT)`；不可用时自动退回「挂抽屉面板」路径（`FTT.openPanel()` 的 `via` 会说明用了哪条路）。

## 5. 配置项（内核配置，设置分页可改）

| 键 | 默认 | 含义 |
| --- | --- | --- |
| `uiShowDrawer` | `false` | 是否同时在扩展设置抽屉里渲染面板卡片（默认否 = 只用弹窗，符合用户偏好） |
| `uiShowFloating` | `true` | 扩展菜单入口不可用时，是否显示右下角悬浮「FTT」按钮 |
| `uiFirstTab` | `overview` | 弹窗默认分页 |

> 这三个键是 **V2 专有**；配置保真门禁（`config-clock-golden` C1）只允许这三个额外键，V1 的 217 键仍逐值一致。

## 6. 视觉与诊断

- 弹窗样式在 `style.css`（`.ftt-pop*`：分页条、内容区滚动、动作行、楼层行、悬浮按钮）；
- `/ftt` 状态新增「界面：弹窗优先（分页 …）· 弹窗能力 … · 抽屉卡片 开/关」与「装配/面板/菜单入口」诊断行；
- `FTT.popupInfo()` 返回 `{ tab, opened, canPopup, showDrawer, showFloating, mount }`。
