# P10c162 · 「旧存档合并提示反复出现」修复（v3.52.9）

> 文档版本：v1.0 ｜ 日期：2026-11-03 ｜ 状态：生效（v3.52.9）
> 用户报告（原话）：「在剧情发生变化后，顶部会不间断出现把旧存档合并到当前提示，且点击生效后，过一段时间又会出现其他的，请修复。」
> 关联：`core/model/rel.js` · `core/model/ledger.js` · `core/archive-scope.js` · `core/migrate.js` · `docs/D60`

## 1. 根因（两处叠加）

### ① 归一化把存档归属**丢掉**了（每次载入/同步后又变「无归属」）

`chatKey` 是插件自维护字段，而各 normalizer（`normalizeRelLink` / `normalizeLedgerEntry` 等）**显式构造新对象**，
未知字段被丢弃 → 每次载入期的 `migrateRelLinks` 等路径一跑，**关联行 / 账本**就重新变回「无归属」；
`mergeHistoryIntoLedger` 由货币历史生成的流水也从没打过归属。
→ 顶部横幅统计到的 `legacy` 数**每次载入都重新长回来**，于是「点一次生效 → 过一会儿又提示」。

### ② 用户的归档选择**没有被记住**

`adoptLegacyEntries` 只处理当下已有的遗留；没有记忆「用户已确认归档」，下一轮载入又会出现新的遗留 → 反复提示。

## 2. 修复

1. **归一化保留归属**：`normalizeRelLink` / `normalizeLedgerEntry` 重建对象时携带 `chatKey`（只保留原值，不推断）；
   `mergeHistoryIntoLedger` 新建流水打当前存档（`stampEntryArchive`）。
2. **记住归档选择**：`adoptLegacyEntries` 成功时写 `state.archiveAdoptAuto = true`；
3. **载入期自动收敛**：`migrateState` 末尾调用 `autoAdoptOnLoad()` —— 仅当「已确认过归档 + 当前存档键已知」时，
   把仍无归属的历史条目归入本档（幂等、只补空值）；未确认过则**零副作用**（不悄悄认领历史数据）。

效果：用户点过一次「归入当前」后，之后的载入 / 同步 / 剧情推进都不会再反复弹出同一提示；
横幅只在「确实还有未归档历史 + 用户从未确认过」时出现。

## 3. 测试

`archive-scope.test.js` 14 → **18 项**：
E1 归一化保留归属（关联行 / 账本，含 `ck` 短键）· E2 归档记忆 + `autoAdoptOnLoad` 幂等 ·
E3 未确认过不动历史数据 · E4 `migrateState` 载入期收敛（新遗留被自动归入、横幅不复现）。

全量单测 **264 文件 / 3921 断言**；冒烟 224 项；`npm run gate` 全绿。

## 4. 边界

1. `autoAdoptOnLoad` 只在**用户已确认过**（`archiveAdoptAuto`）后生效 —— 首次仍由用户点按钮确认；
2. 仍只补**空归属**：别的存档的条目一律不动；
3. 无归属的历史条目归入本档后不再可撤销（与手动归档同口径；建议先导出备份）。
