## 1. 去掉的是什么

| 元素 | 处置 | 依据 |
| --- | --- | --- |
| 分类页顶部「**NSFW 留档：弱 N · 强 M**（按原文判定，弱化后不变；标记见每条末行…）」 | **删除**（v3.9.0 引入；`ui/list-rows.js#nsfwLegendHtml` 函数与导出**一并删除**） | 它只是**当前筛选结果**的计数 —— 筛选前后数字不同、不指向任何动作；用户要看的是"这一条什么等级"，而那已由逐条标签承担 |
| 全部维度列表页（情节 / 记忆 / 状态 / 物品 / 传言 / 计划 / 悬念 / 概念 …） | **两处调用点**都已去掉（通用列表 `return` + 状态分类 `head`） | 同上 |
| 每条**末行**的等级标签 `NSFW·弱` / `NSFW·强`（含级别释义 tooltip） | **保留** | 那是**留档本身**（逐条行动信息） |
| 设定 → NSFW弱化 页的「当前留档：共 N 条 —— 无 x · 弱 y · 强 z」+「🔖 立即补档」 | **保留** | 功能自述 + 唯一的补档计数反馈（不在"各大类顶部"） |
| `nsfw` 字段 / 判级 / 自动补档 / 注入 / 词条分析 | **一字不动** | 本条只删展示 |
