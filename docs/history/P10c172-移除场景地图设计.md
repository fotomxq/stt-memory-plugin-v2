## 2. 下一版（`MAP_PURGE_VERSION = 3.52.20`）：数据清理例程**已备好**

新模块 `core/map-purge.js`（本版只预备、**不自动执行**）：

* `mapLegacyStats()` —— 存量统计（条目 / 关联行 / 墓碑 / 内容墓碑 / 残留配置键）；
* `purgeMapData({force})` —— 一键清干净（只动地图）：
  ① `state.maps` 逐条写墓碑后清空；② `links` 中 `dim==='maps'` 的关联行；③ `deleted.maps` / `deletedH.maps`；
  ④ 运行期配置键 `mapTrailPhrase` / `storeMinMaps` / `storeMaxMaps` / `storeShare.maps`（**删除**而非归零）；
* `applyPlannedMapPurge()` —— **版本闸**：当前版本 < 3.52.20 时返回 `not-yet`（带存量统计），到点后自动执行；
* 下一版接入方式：初始化末尾调用一次 `applyPlannedMapPurge()` 即可（幂等：清干净后再跑为 0 条）。
