## 1. 怎么用

| 你想知道 | 看哪里 |
| --- | --- |
| **现在**系统是什么样 | `docs/01-业务架构` … `docs/05-开发指南` |
| 某个改动**当时**怎么做、证据在哪 | 本目录对应批次档 |
| 某条历史结论**是否已过时** | `docs/勘误-历史档过时条目.md`（只增台账） |
| 打算做什么 | `docs/D*` 设计稿 |

## 4. 新增历史档的要求

1. 文件名：`P<阶段><字母>-<主题>.md`（与已发布版本对应时，主题里带上该版本的要点）；
2. 头部元信息：`文档版本 ｜ 日期 ｜ 状态`（状态写「生效（vX.Y.Z）」）；
3. 正文口径：`用户原话 → ①②③ 改动与理由 → 门禁与回归`（与 `CHANGELOG.md` 条目同源）；
4. **只增不改**：结论变了就追加「结论变更」段落，不改旧文。
