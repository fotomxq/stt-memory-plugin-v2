## 1. 缺陷（2/3）：按钮「全部错误 / 无法使用」的根因

货币三子页的正文由 `ui/money-tabs.js` 渲染，而**面板的编辑器挂载点只在 `dimBodyList(kind)` 里**：

```js
// ui/panel.js#dimBodyList
const ed = ps.editing && ps.editing.kind === kind ? editorHtml(kind, …) : '';
```

`＋ 记一笔` / `＋ 新建标的物` / `✏ 编辑` 都只是把 `ps.editing` 置位 → **重绘时货币页直接替换掉了 `dimBodyList` 的正文** →
编辑器**没有任何地方渲染** → 用户看到的就是「按钮点了没反应 / 无法使用」。

**修复**：`ui/panel.js#dimBody` 把 `{editing, editorHtml}` 传进 `moneyPageHtml(...)`；`ui/money-tabs.js` 在
`editing.kind === 'ledger' | 'deals'` 时把 `editorHtml(kind, id, preset)` 渲染到页面顶部。
—— 这样「＋」与「✏」都真正打开编辑器，保存走既有 `save` 动作（`collectEditorFields` 读 `data-ftt-ed` 字段）。

## 2. 美化（1/4）：两页的列表样式

新增（`style.css`，不在体量基线内）：

* **收支记录**：`ftt-money-summary`（笔数 / 净额 / 收入 / 支出 / 摘要上限 五枚汇总卡）+ `ftt-money-row` 行卡
  （左侧 3px 方向色条 · 日期块 · 货币名 · 来源徽标 · 说明 · 右对齐金额 · ✏/🗑 操作）+ `ftt-money-hint` 口径提示；
* **长期收支**：`ftt-deal-card` 卡片（标题行 + 类型/周期/触发器徽标 · 约定 · 元信息（锚定货币/初始/最后变动/截止）· 现状 ·
  **前景预判三段分区**（① 文字说明 ② 已发生节点 ③ 预测下一节点）+ `ftt-forecast` 预测高亮块（虚线蓝框，与「已发生」明确分区））。
