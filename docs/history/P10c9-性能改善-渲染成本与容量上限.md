## 2. 实测（同一台机器、同一脚本、真实面板路径；热身后中位数）

| 形状 | 指标 | 旧（v3.0.23） | 新（v3.1.0） | 倍数 |
| --- | --- | --- | --- | --- |
| 中库（≈1235 条，无关联层） | 打开界面 / 一次动作 | 239ms / 370ms | **14ms / 11ms** | 17× / 34× |
| 中库（+500 关联行） | 打开界面 / 切到角色页 | 724ms / 1054ms | **11ms / 5ms** | 66× / 211× |
| 满载（≈3540 条 + 2000 关联行） | 打开界面 / 一次动作 / 切到角色页 | 6857ms / 10307ms / 10258ms | **13ms / 13ms / 14ms** | ≈530× / 790× / 730× |
| 角色页单页（200 档案 × 400 记忆 × 2000 关联行） | 单页构建 | 1966ms | **15ms** | 131× |
| 200 次下钻调用 | `characterDrillHtml` | 2319ms | **2ms** | ≈1160× |

> 「旧」数字取自 `git archive v3.0.23` 的干净目录 + 同一脚本（避免方法与机器差异）。
> 「无关联层」一行体现**结构性**收益（13 页 → 1 页、3 遍 → 1 遍）；带关联层的行另外体现**二次增长**被消除。

## 4. 兼容与回退

- **渲染语义**：面板只在当前分页渲染正文 —— 对外接口 `panelBodyHtml(tab)` 逐页可用不变；
  `panelHtml()` 默认返回当前分页版本，需要全量时显式 `{ all: true }`（调试台 / 测试 / 外部调用）。
- **V1 保真度**：行渲染（`ui/list-rows.js`）与关联摘要（`core/model/rel.js`）的**输出逐字节不变**；
  唯一的有意偏离是调试日志**单条长度上限**（排障不依赖 2000 之后的字符）。
- **数据安全**：关联层裁剪**只**在超过 `max(200, 条目数 × 2)` 时发生，先删孤儿、被裁行写墓碑并可 `dryRun` 预演；
  本机缓冲超预算只影响**本机缓冲**这一层（服务端文件 + IndexedDB 照常写，旧内容不清空）。
- **回退**：渲染侧如需退回旧口径，可在调用处改回全量构建（`{ all: true }`）与 `renderPanel` 的二次构建；
  容量侧的上限都有导出的 setter / 覆盖入口（`setVectorCacheCaps` / `capRelLinks({max})` / `setLocalBufferMaxChars`）。
