## 3. 措辞一致性规则（本轮确立）

1. 页面提示 = **一句话**（≤ 90 字，正常 ≤ 40 字）；超出的解释放 `hintDetailsHtml()`（默认收起，触屏可点开）。
2. 强调一律用 `<b>` 或 `mdBold()`，**不写 Markdown 星号**（避免原样显示）。
3. 按钮/状态文案统一动词开头、去掉版本号与实现细节（如「导入旧版数据（干跑）」）。
4. 不再出现跨页「已移至…」指路、与按钮 `title` 重复的解释、以及同一句重复。

## 5. 未验证 / 风险

1. 体检覆盖**页面提示**；`title` 悬停提示与折叠说明里的文本未做长度门禁（它们本来就不占版面）。
2. 规则 D1 用词表驱动（如「批次」仅拦「批次接入/后续批次」这类开发语境，避免误伤「单轮批次数上限」）。
3. 若后续新增页面提示，门禁会立即失败——这正是本轮想要的防回归效果。
