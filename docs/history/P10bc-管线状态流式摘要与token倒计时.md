# P10bc · 管线状态：流式摘要 + token 计数 + 预估倒计时（v2.90.0）

> 文档版本：v1.0 ｜ 日期：2026-09-27 ｜ 状态：生效（v2.90.0）
> 触发（用户原话）：「管线状态中的提示信息，补充流式更新细节，不需要让用户看到具体内容，只提取一些摘要展示，
>   让用户感知正在处理。其次除了读秒，还需增加 token 计数、预估倒计时。其中预估倒计时，可内置记录最近几次
>   不同处理行为的耗时作为参考。如果为第一次，则给一个潜在默认时间作为倒计时。」
> 落点：`core/pipeline.js`（新）· `core/ai-hooks.js`（AI 调用统一进管线）· `ui/panel.js`（管线状态行）· `index.js`（历史持久化接线）

---

## 1. 交付

| 项 | 实现 |
| --- | --- |
| **① 流式摘要（不泄漏内容）** | 新增 `core/pipeline.js#summarizeResponseKeys`：只从 AI 响应里提取**顶层键名**（如 `情节 / 记忆库`），过滤 `新增/更新/删除/标题/内容…` 等二级键 → 状态行显示「识别到 情节 / 记忆库」。**永不显示正文**；另显示「流式 N 块 / 响应 N 字」等结构信息（`addStreamChunk` 只累计字符数与块数） |
| **② token 计数** | `estTokens(chars) = ceil(chars / 4)`（中英混排近似）；**prompt 与响应分别计**（发送前按消息正文长度估 prompt，响应按分块/整段累计），状态行显示 `🪙 1.2k tok`（千分位缩写） |
| **③ 预估倒计时** | 状态行显示 `预计剩 8s`；**按处理行为标签**（批量摘要 / 单楼分析 / 自动修复 / 推演 / 传言演化 / 向量检索 / 弱化NSFW / 时钟巡检 / 情节总结…）分别取**最近 5 次**耗时均值（样本 ≥3 时**去掉最大最小各一个**，抗单次抖动）；**首次无历史 → 用内置默认表**（如批量摘要 20s / 单楼分析 6s / 向量 2.5s）并在文案标注「（默认）」；超时改为「已超预估 Xs」 |
| **④ 持续刷新** | 沿用既有 **500ms 心跳**（`ui/panel.js#syncPipelineTick`）：忙位期间状态行**持续更新**读秒 / token / 倒计时 / 摘要；空闲与关闭面板即停表（不泄漏定时器） |
| **⑤ 历史持久化** | `index.js` 注入 `setPipelineHooks({ getHistory, saveHistory })` → 读写 **ST 扩展设置** `pipelineEta`（`{行为: [ms…]}`，每个行为最多 5 条）——**不进数据模型**，`DATA_VERSION` 保持 1 |
| **⑥ 接入点** | `core/ai-hooks.js#aiCallText`（全部 AI 调用唯一出口）：调用前 `beginPipeline(label, { chars })` → 期间可 `onToken` 分块 → 响应后 `summarizeResponseKeys` + 阶段推进「解析响应」→ `endPipeline(ok)` 记录本次耗时（失败也入样本）；向量 / 嵌入调用不经过该出口，故不占用 ETA 样本 |

## 2. 状态行示例

```text
空闲
正在分析记忆（AI 摘要） · 分段 2/4 · 第 5-8 楼 · 批量摘要 · 已用时 3s · ⏱ 0s · 🪙 3.5k tok · 预计剩 20s（默认） · 流式 1 块 · 阶段：准备
```

- 「已用时」= 批次读秒（既有口径，来自 `batchProgress().since`）；
- `⏱ / 🪙 / 预计剩 / 流式 / 阶段` 由 `core/pipeline.js#pipelineSuffix()` 生成，**与 UI 解耦**（可单测）；
- 有历史之后「（默认）」消失，倒计时改用实测均值。

## 3. 口径与边界

| 项 | 口径 |
| --- | --- |
| token 是**估算** | 无宿主用法统计（本项目走 `generateRaw` 类接口，响应不带 usage）→ 统一 `ceil(字符数/4)`；文案只显示估算值，不声称精确 |
| 只显示**结构**信息 | 摘要 = 顶层键名 + 阶段 + 字数/块数；**不含任何正文片段**（单测 D1 显式断言不泄漏「码头/木箱」等正文词） |
| 样本不分成功失败 | 失败往往更快；当前统一入样本（更准的分组留待后续；如需可分「ok/fail」两表） |
| 历史范围 | 每个行为保留最近 **5** 次；`pipelineEta` 存 ST 扩展设置，跨会话保留、随角色作用域共享（与词条/界面设置同级） |
| 未做 | 更细粒度的「分段级 ETA」（按已完成段的实测速度外推剩余段）与真实 token 流（宿主是否回调 `onToken` 取决于 API 通道；已预留 `onToken` 钩子） |
