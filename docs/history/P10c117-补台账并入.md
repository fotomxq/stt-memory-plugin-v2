## 1. 自检发现的问题（如实登记）

v3.50.7 给 `mergeV1IntoCurrent` 加了 `mergeRuntimeSlots`，但**台账那一段写错了形态**：

- 台账的**规范形态是数组**（`processedFloors: [{f,h,at?,ck?}]`，见 `core/migrate.js#healthSelfHeal`）；
  而我把源代码里的旧形态（「楼层号 → `{f,h}`」映射）当成规范形态去并 → `mergeV1IntoCurrent` 里的
  `migrateState` **先把非数组台账清空**（`core/migrate.js` 的「非数组 → `[]`」），我再去并**空对象** → 一条都没进去；
- 更糟的是：**我的单测夹具也用了映射形态** → 两侧都被清成空 → 断言 `{} === {}` **空对空假通过** ✗
  （单元测试全绿，但真机往返仍是「台账归零」）。

**这是本轮最该记住的教训**：断言必须落在**真实形态**上；两边同时被同一个净化逻辑清空时，「相等」不代表「还原」。
