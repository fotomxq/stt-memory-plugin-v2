## 1. 两处缺陷（v3.49.2 留下的）

| # | 现象 | 根因（逐行核对） |
| --- | --- | --- |
| 1 | 列表**挤压到一起**（右侧 🔧 掉到下一行） | v3.49.2 的「正在整理…」状态行写在 `.ftt-item-main` **之外**：`<div class="ftt-item-main">…</div>` + `<div class="ftt-muted ftt-w-full">…</div>` + `<div class="ftt-item-ops">…</div>`。`.ftt-item` 是**横向 flex**（`.ftt-item-main{flex:1}` + `.ftt-item-ops{flex-shrink:0}`）→ 第三个子项迫使换行，🔧 被挤走 |
| 2 | **看不到任何动效** | `.ftt-loading` 在 `style.css` 里**只有** `#ftt-panel .ftt-floor-btn.ftt-loading`（与它的 `::before` 转圈）两条规则 → 加到 `.ftt-item` / `.ftt-op` 上等于**空样式**（无转圈、无变色、无高亮） |

## 2. 修法

| 面 | 改动 | 落点 |
| --- | --- | --- |
| 布局 | 状态行移进 `.ftt-item-main` **内部**，新类 `.ftt-item-sub`（`display:block; margin-top:3px`） | `ui/currency-merge.js` · `style.css` |
| 行级加载态 | 新类 `.ftt-item.ftt-item-loading`：底色 + 左侧强调条 + 呼吸动画（`fttPulse`）—— **动画被全局禁用时仍可见**（底色/强调条不依赖动画） | `style.css` |
| 转圈 | 新通用类 `.ftt-spin`（`fttSpin` 无限旋转）；按钮 `.ftt-op.ftt-loading`（同款 `::before` 转圈 + `pointer-events:none` + 禁用色） | `style.css` · `ui/currency-merge.js` |

## 3. 测试

- `F2`（扩展）：在途行须同时具备 `ftt-item-loading` / `ftt-spin` / `ftt-op … ftt-loading` / `disabled`，并断言**位置有序** `ftt-item-main < 状态行 < ftt-item-ops` ← **"挤压"的回归锁**；
- `F5`（新增反向锁）：`style.css` 必须真的定义那四个类与 `@keyframes fttSpin`，且行级加载态含 `background` + `box-shadow` ← **"看不到动效"的回归锁**。
