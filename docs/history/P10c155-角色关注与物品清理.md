## 1. 角色「关注」标记（免自动清理）

* 数据：`snapshots[].watch` —— **只在 true 时写**（false 与缺省等价：省体积、V1 黄金样本零漂移）；**不进内容哈希**（用户标记，不是剧情内容）；
* 豁免：存档上限裁剪（`core/ingest.js#enforceDimCaps` 按「高重要度」同档保护）与低使用遗忘（`core/forget.js` snapshots 项跳过）；
* 名单 API：`core/snapshot-watch.js#watchedRoleNames / roleProtected / toggleSnapshotWatch`；**主角恒受保护**（`defaultCurrencyOwner()`）；
* 界面：角色行「☆ 关注 / ⭐ 已关注」（`data-ftt-action="watchToggle"`，即改即落盘）+ 行首「⭐ 关注」徽标 + 编辑器勾选框。

## 2. 清理未关注角色的物品（**两步式**）

* 数据：`items[].owner`（归属角色）—— **只在非空时写**；`HASH_FIELDS.items` 含 owner（瘦身保留），但**内容哈希不含**（边界登记：归属属元信息，跨端仍按 id + updatedAt 合并）；
* 计划：`core/items-cleanup.js#itemsCleanupPlan()` **只读**、幂等 —— 候选 = `owner` 非空且**非关注/非主角**；未归属 / 关注 / 主角名下 **一律不动**；
* 应用：`applyItemsCleanup()` 逐条 `deleteEntry('items', id)` → **双墓碑** + 级联关联行（与手动删除同一路径）；
* 界面：物品页「🧹 清理未关注角色的物品」→ 公共预览卡（逐条「剔除」清单 + 按归属分组数量 + 保留/未归属统计）→ **危险动作二次确认** → 删除；取消零副作用。

## 5. 边界（如实登记）

1. `owner` 不进内容哈希 → 跨端「只改归属」可能不触发合并（按 id + updatedAt 兜底；清理以本端字段为准）；
2. 清理**只认显式 owner**，不做「描述/标签含角色名」的模糊推断（未归属一律不动）；
3. 关注只免**清理**，不阻止角色修复/合并对内容的改写（那属于内容维护，不删条目）。
