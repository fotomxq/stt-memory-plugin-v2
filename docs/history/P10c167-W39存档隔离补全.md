## 2. 根因

1. v3.52.7 的读侧分区把 `legacy` **保留可见**（打标）——真机 `legacy` 恰恰是**别条聊天**的旧数据 → 每条聊天都能看到 = 「内容交叉」；
2. 货币流水 / 长期收支的读接口（`ledgerList()` / `dealList()`）**未分档**；
3. 楼层收缩把**所有**条目与**整本台账**按当前聊天重算：别档条目被平移/钉到本档楼层、判「原文已移除」；`0/0` 区间条目被台账代理钉到第 0 楼（各档开场白相同 → 哈希必然相同）；台账整批重建会丢别档标记；
4. 归属证据②（`floorFingerprintHit`）把上述被钉住的第 0 楼位置当「本档证据」→ 误认领。
