>   补充：「货币可以手动添加，这个没异常。只是注入机制、提示词变更机制存在缺陷，AI无法正常自动变更货币。」

## 0. 三处叠加缺陷（任一处都足以让「自动变更」失效）

| # | 缺陷 | 位置 | 现象 |
| --- | --- | --- | --- |
| ① | **注入匹配方向写反** | `core/recall.js#buildMemoryBodyForInject`：`hay.includes(q)` 拿**整段正文**去比「归属+币种+备注」 | 非主角货币**从不注入** → AI 没有账本参照 |
| ② | **模板为空/缺失 → 整维静默消失** | `core/prompt.js#buildSummaryPrompt`：`else if (pt[d])` | 旧存档 / 误清空 / 迁移缺键 → 【货币】块整段消失 → AI 收不到指令 |
| ③ | **提示词缺「资金变化」触发规则** | `core/prompts-v2.js` currencies 块 | AI 遇「说不清具体数字」就**整条不记** |

「手动添加正常」正是因为面板写入不经过这三处（不依赖提示词、不依赖注入匹配）。

## 1. 修复

### ① 注入匹配（`core/recall.js`）

```text
hitKw = nameMatch(owner, q) || q.includes(币种名) || q.includes(备注) || tagMatch(tags, q)
      || (单位 && 资金变化词 && q.includes(单位))
```
「单位 + 资金变化词」这条专治「账本写 `银元`、正文写 `银币`」的写法差异，同时避免「一枚戒指」误伤。

### ② 模板兜底（`core/prompt.js`）

新增 `tplOf(key)`：`cfg.promptTemplates[key]` 为空串 / 缺失 → 回落 `PROMPT_TEMPLATES_V2[key]`，并 `dbgLog('提示词', …)` 留痕。
自定义内容优先；「清空模板」不再等于「禁用维度」（禁用请用 `dimensionEnabled`）。

### ③ 触发规则（`core/prompts-v2.js`，**V1 黄金偏离**）

```text
触发（**强制**）：正文出现资金的收 / 支 / 转移 / 找零 / 报数 / 余额变化时，必须输出【货币】条目；
没有精确总额也要记 —— 给出本次收支即可（额度按净额推算）。
```
按 `开发守则.md` §2.4 三件套登记：**黄金样本一字未改**，`extract-prompt-flow#P1` 与 `separate-dim-golden#G2`
在测试内**显式剔除该行**后再逐字符比对，并新增 P1b 正面断言。

## 3. 边界（如实登记）

1. 不改货币融合/拆分口径（`应-32` 另案）；不做汇率换算；不改 `DATA_VERSION`。
2. 「单位 + 钱词」匹配是启发式：宁可少注入也不制造噪音（单测 A2 锁）。
3. 提示词触发规则属有意偏离：若后续要回退，删该行 + 两处测试归一即恢复 V1 逐字口径。
