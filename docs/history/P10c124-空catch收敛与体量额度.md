## 1. `技-55`：空 catch 收敛（**217 → 0**）

**缺陷**：全仓 **217 处** `catch (e) { }` 静默吞异常 —— 真机排查时无从判断「这行失败意味着什么、能不能忽略」。

**修法**：新增工具 `scripts/repair-empty-catch.js`（**零逻辑改动**，只加注释）：
- 识别「真·空 catch」（单行 + 多行形态）；
- 从 **try 块里的第一个调用** 推断**具体**忽略原因（内置规则表 15 类），改写为 `catch (e) { /* 忽略：<原因> */ }`；
- **只扫出货面**（`core/ host/ adapters/ ui/ index.js`）：`scripts/`、`tests/` 属工具面，且测试夹具里常有
  `catch (e) { }` 的**样本字符串** —— 本轮第一版没排除，把 `tests/unit/tech-gates.test.js` 的样本改坏（已回滚，见 §4）。
