# P10c169 · 删除「其它存档」数据（非当前存档的全部数据）（v3.52.16）

> 文档版本：v1.0 ｜ 日期：2026-11-18 ｜ 状态：生效（v3.52.16）
> 用户要求（原话）：「设置的删除角色删除数据位置，新增其他删除选择。包括删除非当前存档的其他存档数据。该操作可以删除非当前存档的其他所有存档数据。」
> 关联：`core/archive-purge.js`（新）· `ui/settings-pages.js` · `ui/panel.js` · `core/archive-scope.js`

## 1. 背景

v3.52.7 起记忆按聊天存档分区：其它存档（`chatKey` ≠ 当前）**默认隐藏**、不参与注入/清理，但**仍占空间**。
数据管理页此前只有「清空当前角色记忆」，没有「清掉其它存档」的出口。

## 2. 新增：删除其它存档数据

* **入口**：设定 → 数据管理 → ⚠️ 危险操作 → 「🗑 删除其它存档数据（N 条）」
  （`data-ftt-action="purgeOtherArchives"`；N = `archiveStats().other`，为 0 时**禁用**）。
* **范围**：只删 `chatKey` 非空且 ≠ 当前存档的：
  * 各维度条目（`atoms/currentStates/snapshots/memories/items/plans/suspense/concepts/scenes/npcs/rumors/parallels/currencies/maps/plotSegments/ledger/deals`）；
  * 关联行（`links`，按自身归属；条目删除时会级联清掉对应行）；
  * 楼层台账（`processedFloors` / `processedDropped` 中 `ck` 非空且 ≠ 当前的标记）。
* **不动**：当前存档的数据；**历史遗留**（无 `chatKey`，无法安全判定归属）。
* **删除路径**：逐条 `core/entries.js#deleteEntry` → **写双墓碑**（跨端不复活）+ 级联关联行 / 货币流水；
  之后 `saveState()` 落盘并写调试日志（只记计数，不含正文）。
* **安全闸**：① 危险动作**二次确认**（`DANGER_ACTION_PROMPTS.purgeOtherArchives`）；② 当前存档键**未知 → 拒绝执行**（`no-current-archive`，绝不猜着删）；③ 幂等（再跑一次为 0 条）。

## 3. 测试

新增 `tests/unit/archive-purge.test.js`（**5 项**）：
A1 只删其它存档（条目/关联行/楼层台账按归属清理，当前档与遗留不动，写墓碑）· A2 幂等 ·
A3 当前存档未知拒绝 · A4 面板动作 + 危险确认文案 + 按钮条数 · A5 无数据时按钮禁用。

全量单测 **270 文件**（断言数以门禁实测为准）；冒烟 224 项；`npm run gate` 全绿。

## 4. 边界（如实登记）

1. 只能删「**有归属且不是当前存档**」的数据；无归属的历史遗留**不会被删**（判不出来就不删）；
2. 删除写墓碑 → 对端同步后**不会复活**；本机也无法通过「最近删除」恢复正文（墓碑只防复活）；
3. 这是**不可恢复**操作：建议先「⬇ 导出 JSON 文件」备份。
