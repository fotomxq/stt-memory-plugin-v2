## 1. 数据层

* **`ledger`**（`core/model/ledger.js`）：`currencyId` 必填且必须指向现存货币；`date`/`delta`（非 0）/`note`/`source`/`dealId`；
  `id = led_<hash(currencyId|date|delta|note)>` → 幂等；记账 = 写账本 + 余额 += delta + 摘要刷新；删除 = 冲正 + 墓碑；
  **货币消失 → 级联删除**（逐条墓碑）；`reconcileLedger` 只报不改；`backfillLedgerFromHistory` 迁移回填。
* **`deals`**（`core/model/deal.js`）：`name`/`desc`/`kind`/`startDate`/`lastChangeDate`（自动）/`endDate`/`status`/
  **`currencyId` 必填**/`cycle`/`outlook{text,nodes,forecast}`；**`forecast.nextDate` 必填**；方向与符号矛盾以符号纠正；
  `cycle` 缺省由节点间隔推断；`trigger` 只读（代码维护）。
* **六处接线**：常量（维度/原子层/`DATA_VERSION` 3）· 状态容器 · `KIND_MAP`/中文键 · 归一（`entries.js`）· 内容哈希（`hash.js`/`HASH_FIELDS`）·
  瘦身白名单与同义组 · 迁移（补容器 + 回填）· 跨端逐条合并（`ATOM_DIM_KEYS` 自动带入）· `state-slots` 槽位登记 · `STORE_LIMITS`（占比 0）。

## 2. 触发器（`core/deal-triggers.js`，确定性·无 AI）

* 判据：`jump`（跨度 ≥ 30 天）；`backward`/`invalid` 不兑现；
* 兑现：`forecast.nextDate ≤ 当前剧情日期` → 生成 `source:'deal'` 流水 + 节点提升；幂等（`dealId+节点日期`）；
* 货币丢失 → 不生成 + `trigger.skippedReason='currency-missing'`；
* 猛烈跳动（≥3 周期）→ 按 `cycle` 补齐，受 24 节点上限，超限 `catchUpTruncated`；
* 接线：`index.js#runDealTriggersAfterExtract`（薄包装）挂在 `onGenEnded → runAutoExtract()` 之后，失败静默。
