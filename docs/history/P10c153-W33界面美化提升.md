## 2. `技-60` CSS 设计令牌收敛 + 门禁

* 补齐此前**引用却未定义**的令牌：`--ftt-text` / `--ftt-fg*` / `--ftt-err`；新增收支与警示色 `--ftt-in` / `--ftt-out` / `--ftt-warn*` / `--ftt-ok-line` / `--ftt-info*`；
* 两套 `#ftt-panel` 变量块**合并为一套语义**：旧名（`--ftt-panel-bg` / `--ftt-border*`）改为新令牌的**别名**（不再重复字面量）；
* 散落硬编码色值（`#57c98a` / `#e8705f` / `#6aa9ff` / `#3f7d5c` / `#8a6b2f` …）收敛为令牌；
* `scripts/check-ui-spec.js` 新增 **C13：`var(--ftt-*)` 未定义即报**（运行态注入的 `--ftt-range-def` / `--ftt-swipe-w` 走白名单）。

## 4. `应-48` 总览仪表盘化

* 双栏仪表盘 `ftt-dash-top`：左「剧情时钟卡」、右「记忆类目网格（可下钻提示）」；
* 工具行按 `docs/D23` **B 写库 / C 读库 / D 维护 / E 存取** 四区（`data-ftt-dash-tools` + `data-zone`）；
* 类目统计改 `ftt-cat-grid`（`auto-fill` 自适应）；窄屏单列。

## 5. `应-49` 子标签统一 + 设定四分组

* 新组件 `ui/subtabs.js`：**分段胶囊** + 窄屏横滚两端渐隐；DOM 契约不变（仍 `ftt-subtab` + 各页 `data-ftt-*`）；
* 设定 15 子页按四簇分组（内容与投喂 / 记忆与整理 / AI 与风险 / 数据与排障），未登记新页自动落「其它」，**永不丢页**。

## 6. `应-50` 列表卡片 · 状态组折叠 · 场景树去内联

* 列表行三段式卡片（CSS 层级：标题行 / 正文 / 底栏元信息 + 徽标）；
* 状态页角色组：字段数角标 + **纯 DOM 折叠**（`data-ftt-stategroup*`，不落盘）；
* 场景树：内联样式全部改为类（`ftt-scene-d0..8` / `ftt-scene-hit-row` / `ftt-scene-cur-leaf`），`data-ftt-scene-node` 契约不变。

## 7. `应-51` 公共预览卡片

新组件 `ui/preview-card.js`（操作徽标 + **变更前 → 变更后** + 依据；op ∈ add/del/mod/report），
三域联动 / 货币融合 / 货币修正统一套用 `ftt-preview-card` 视觉；履历批量沿用同族样式。

## 8. `应-52` 长表单分组与多值结构化

* 角色档案 22 字段 → **4 个可折叠分组**（身份 / 外貌与性格 / 背景 / 关系与未来，次要默认收起）；
* 必填项标星（`ftt-req`；真正拒绝仍在归一函数）；
* 平行事件 `goalOdds` → **结构化「目标 / 可能性」行控件**（`oddsTable`，加/删行纯 DOM），旧 JSON / 分隔符输入仍兼容。

## 10. 边界（如实登记）

1. 纯界面层升级：**不改任何业务数据契约**、不改 `DATA_VERSION`、不改跨端哈希（`D55` N1–N5）；
2. 子标签 / 列表行 / 预览面板仍是**字符串渲染**（无框架、无构建步骤）；
3. 状态组折叠是**视图态**（不落盘，刷新回到展开）；
4. 编辑器分组对 `snapshots` 生效；其余维度字段少，保持单组平铺。
