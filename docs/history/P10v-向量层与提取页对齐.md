## 2. 新增模块与职责

| 文件 | 职责 |
| --- | --- |
| `core/vector.js` | 纯内核：`cosineSimilarity`（V1 逐字）、`meanVector`（关键词前 5 求均值）、`vectorBank`（6 类候选与 V1 同键同文本，embedding 文本截 300 字）、`rankVector`（降序 + TopN + minScore） |
| `adapters/vector-cache.js` | IndexedDB 库 `FTTMemoryVectorCache` / 表 `embeddings`（**与 V1 同名同结构**，可互读）；无 IndexedDB → 内存回退；`vectorCacheClear/stats` |
| `host/embeddings.js` | `vectorTarget(kind)`（自填地址 或 **本插件 API 分组**）、`requestEmbeddings`、`requestRerank`（兼容 `results[]`/`data[]` 两种返回）、`vectorLayerInfo`；端点/鉴权/请求体/超时/日志与 V1 同口径 |
| `host/vector-recall.js` | 编排：候选库 → 缓存命中 → 缺项 embedding → 写缓存 → 关键词均值 → 余弦 TopN → Rerank 精排 → 注入行；返回 `stats`（库规模/缓存/维度/是否精排）与失败原因 |
| `host/ai-recall.js` | 第三层：`extractKeywordsFromText`（`keywordExtract` 模板 + kw 目标）、`analyzeMemorySend`（`memorySend` 模板 + 【当前剧情日期】+【关键词】+【记忆库】+【最近对话】）、`aiLayerInfo` |
| `host/extract-flow.js` | 三层编排：命中即返回、逐层降级；`runExtractFlow` / `testLayer`（单层测试） |
| `ui/extract-page.js` | 提取页（V1 三层布局 + Embedding / Rerank 区块 + 测试结果态 + 缓存统计 + kw / mem 分组） |
| `host/inject.js` | 发送前：`useVector` / `useKeywordFlow` 开启时先走三层流程，命中即用其行；否则/失败回落本地召回（默认关闭时行为与旧版完全一致） |

## 3. 与 V1 的有意差异（逐条登记）

| # | V1 | V2 | 原因 |
| --- | --- | --- | --- |
| ① | 「代理预设名」= TavernHelper 预设（`getPreset(name).settings.apiurl/key`） | 等价物 = **本插件 API 分组**（`cfg.apiPresets[name]`，键名仍为 `embeddingProxyPreset` / `rerankProxyPreset`） | 原生扩展拿不到 TavernHelper 预设清单；分组同样承载「地址 + Key + 模型」且可在「API」页维护 |
| ② | `vectorMinScore` 有键但打分只用 `score > 0` | 打分用 `> cfg.vectorMinScore`（默认 0.35） | V1 该键无消费者（死键）；V2 让其真正生效，测试可设 0 复现 V1 行为 |
| ③ | Rerank 只有设置与测试，搜索路径未调用 | 配置了 Rerank 时**真的精排** | V1 页面文案已承诺「可 rerank 精排」，V2 落地 |
| ④ | 关键词一律来自 AI（kw API）或 JS 抽取 | 先 JS 抽取；空且正文非空时再请求 kw API | 与 V1 `testLayer` 的分支顺序一致（V1 注入路径亦为「关键词优先 AI，其次 JS」；V2 把免费的 JS 放前面更省调用，已在此登记） |

## 5. 未验证 / 风险

1. 真实第三方 Embedding / Rerank 服务未在本环境实测（无外网 + 无 Key）：协议按 OpenAI 兼容 `/embeddings`、
   Cohere/Jina 风格 `/rerank` 实现，均以 fetch 桩验证；真实服务若返回异形（如 `{embeddings:[[…]]}`）会被判「返回不完整」并降级。
2. 浏览器直连第三方服务受 CORS 限制（V1 同样如此）；失败会如实写调试日志并降级，不影响聊天。
3. 向量缓存与 V1 共库同名 —— 若同一浏览器先后运行 V1 与 V2，缓存**互相复用**（同键同结构，语义一致）；
   若模型更换，旧向量会与新查询向量维度不同 → 余弦返回 0（不会误召回），可用「🧹 清空向量缓存」重置。
