## 3. 核对时又抓到的真缺陷（上版即有）

`applyPlotSegmentResult` 命中「同时间范围 → 跳过」时**不把本批 `atomIds` 并进已有段** →
该批永远"未被覆盖" → **增量永不收敛**，每点一次重复提交同一批。
**修法**：命中同段时并入（并集、只增不减；正文/时间范围不改写；`out.ids` 语义不变）。复测：全部覆盖后再点 → **0 次 AI**。
