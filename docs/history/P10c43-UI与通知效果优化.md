## 1. 为什么要做「优化通知」——三条**写了但从没生效**的死代码

| # | 证据 | 后果 |
| --- | --- | --- |
| ① | `style.css` 的 `#toast-container .ftt-toastr--info / --analysis / --success / --warning / --error / --sync / --weave / --repair`（8 类行为配色 + 文件头注释「统一消息弹窗（notify → ST toastr）—— 行为配色（左侧色条）」）—— **全仓库 grep `ftt-toastr` 只有 CSS，没有一行 JS** | 所有通知长得一模一样；「推演世界=粉 / 同步=紫 / 修复=青」的识别色从未出现 |
| ② | `index.js#setNotifyHooks` 只按 4 类分流（`error / warning / success / 其余→info`），而 `core/parallel.js` 实际在传 `'weave'` | 推演世界的通知静默降级成普通 info |
| ③ | 调 toastr 时**不传 options**（`fn.call(t, text)` 单参） | `escapeHtml` 默认 false（记忆正文/条目标题里的 `<...>` 被当 HTML 渲染）；无 `preventDuplicates`（连环报错刷屏）；无长度上限（超长文案撑爆通知）；错误与普通提示停留时间相同 |
| ④ | `style.css` 的 `.ftt-note.ftt-note-err` 同样没有任何 JS 用过 | 面板提示行「失败 / 未就绪 / 被拒绝」与「已完成」长得一样 |
| ⑤ | `style.css` 里 `--ftt-danger: var(--ftt-danger)` / `--ftt-success: var(--ftt-success)` | **自引用变量 = 无效值**（真实取值来自下方「视觉体系 v2」令牌块）；这两条声明一直是摆设 |

## 2. 落定口径

### 2.1 通知（新增唯一出口 `ui/notify.js`）

| 结论 | 口径 |
| --- | --- |
| kind 全量归一 | 8 类规范 kind（与 CSS 一一对应）；英文别名（`warn/err/fail/ok/done/fatal/caution/debug…`）与**中文类别词**（`推演→weave` / `同步→sync` / `修复→repair` / `分析→analysis` / `成功/警告/错误`）统一；未知与非字符串一律 `info`（绝不丢通知） |
| 细粒度只体现在**配色** | 宿主方法仍只有 4 种（`weave/analysis/sync → info`、`repair → warning`）—— 这样「识别色」有了，但不会把普通信息伪装成警告/错误 |
| 一次调用带全选项 | `escapeHtml: true`（正文不当 HTML 渲染）· `preventDuplicates: true`（同文案不叠加）· `closeButton` / `progressBar` / `newestOnTop` · **分级停留**（错误 10s / 警告·修复 7s / 普通 4.5s；`extendedTimeOut` 取一半） |
| 文案归一 | 压连续空白 + 折叠换行 + 截断到 **300 字**（CSS 再限 6 行）——通知不是日志 |
| 不改宿主布局 | **不传** `positionClass`（跟随酒馆自身的通知位置设定） |
| 唯一出口 | `index.js#setNotifyHooks` 一处落地；面板 `hooks.notify` 与删楼 `floorTrim.notify` 也最终经它 —— 三处实现收口为一份 |
| 兜底 | 宿主 toastr 忽略 `toastClass` 时，`onShown` 回调里再补一次类（兼容 DOM 元素与 jQuery 对象） |

### 2.2 UI

| 结论 | 口径 |
| --- | --- |
| 面板提示行分级 | `setNote(text, level)`：`err`（红）/ `warn`（琥珀）/ `ok`（绿）/ `''`（中性）四档；**显式优先、否则按保守标记词推断**（只认「失败 / 未就绪 / 未完成 / 已拒绝 / 无效 …」这类明确措辞）→ 既有 ~150 处调用零改动即获得正确分级；`panelState().noteLevel` 可读 |
| 无障碍语义 | 模态 `role="dialog" aria-modal="true" aria-label`；标签条 `role="tablist"` + 页签 `role="tab" aria-selected`；关闭按钮 `aria-label`；提示行 `role="status" aria-live="polite"`。**纯新增属性**，类名与 DOM 结构不变 |
| 焦点可见性 | 关闭按钮 / 页签补 `:focus-visible` 焦点环；禁用按钮 `cursor: not-allowed` |
| 死声明清理 | 删除自引用 CSS 变量两条并注明真实取值位置 |
