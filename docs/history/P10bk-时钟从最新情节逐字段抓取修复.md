# P10bk · 获取时间：没有从最新情节自动抓取数据（v2.98.0）

> 文档版本：v1.0 ｜ 日期：2026-09-28 ｜ 状态：生效（v2.98.0）
> 触发（用户原话）：「获取时间，没有从最新情节自动抓取数据，请核对并修复错误。」
> 核对对象：`core/recall.js#latestTrustedPlot` / `core/clock-extract.js#resolveStoryClock / storyClockReference`
> 相关：`docs/history/P10o-时钟改版-只取最新情节.md`（v2.51.0 的既定契约：**时钟唯一可信来源 = 情节**）

---

## 1. 根因：一条节点扛三个字段

v2.51.0 的契约是「时钟只取**最新一条情节**的 `date`/`time`/`location`」，实现却是：

```js
const plot = latestTrustedPlot({ needDate: true });   // ← 只挑一条，且要求它带日期
out.date = plot.date; out.time = plot.time; out.location = plot.location;
```

于是**只要最新情节缺日期，整条就被跳过**，时钟退回「次新那条带日期的旧情节」并把它的
日期 / 时间 / **地点**一起采用 —— 时间自然不是最新情节的。四种表现：

| # | 情况 | 修复前行为 | 用户可见症状 |
| --- | --- | --- | --- |
| ① | 最新情节**有时间、没日期**（AI 常见输出） | 整条跳过 → 用旧情节的 date+time+location | 「时间没有从最新情节抓取」 |
| ② | **所有情节都没有日期** | `resolveStoryClock` 返回全空 → 时间/地点也不落盘 | 总览「⏱ 时间」灰字显示「（参考最近情节：深夜）」而字段始终为空 |
| ③ | 参考值与实值矛盾 | `storyClockReference()` 用**不带 `needDate`** 的挑法（= 最新情节），与取值口径不同 | 同屏出现「参考最近情节：深夜」与「时间：08:00」（旧值） |
| ④ | 情节**没有楼层信息**（导入的旧数据 / 删楼后置为未知区间 `0/0`） | 排序以楼层降序为主键 → floor 0 排最后 → 它的日期/时间**永远取不到** | 明明有更新的情节，时钟不动 |

> ④ 的补充说明：面板「➕ 新增 / 编辑」写入的条目**会**带上当前楼层（`core/entries.js#upsertEntry` 用 `getLastMessageId()`），
> 所以「手动加一条」通常不受影响；真正受影响的是**导入的旧数据**与**被删楼置为未知区间**的情节。

## 2. 修法

### 2.1 抽出「可信情节列表」（`core/recall.js#trustedPlotList`）

- **筛选口径不变**：排除 `validity === 'inactive'`、`hidden` / `summarizedBy`（已总结隐藏）、`mergedSummary`（情节总结条）；
  其它数据类别（记忆 / 角色 / 物品 / 场景 / 状态…）**一律不参与**。
- **排序**：`两边都有楼层信息` → 仍以**楼层降序**为准（原口径，黄金样本保护）；
  否则（有一方无楼层信息）→ 用**剧情日期**判谁更新；都无日期时才回落到「有位置的在前」。

### 2.2 `resolveStoryClock` 改为**逐字段**取值

```text
date     ← 列表中最新的「有日期」的节点
time     ← 列表中最新的「有时间」的节点
location ← 列表中最新的「有地点」的节点
```

- 仍**只在情节内**取值（绝不引它源）；
- 任何字段所有情节都没有 → **保持原值**（不清空）；
- **一条可信情节都没有** → 整轮不改动时钟（原口径）；
- 日期与时间若来自**不同**情节，取值追踪会写明「（与日期不是同一条：日期取自更早那条）」；
- 「第 N 天」保留字段仍记到**提供日期的那条**情节（无日期可取时退到最新一条）。

### 2.3 `storyClockReference()` 与取值**共用同一口径**

灰字参考（字段为空时的兜底显示）改为同样的逐字段取法 —— 于是「参考最近情节」要么与实值一致，
要么确实所有情节都没有该字段（而不是「有参考值却没采用」）。

## 3. 修复前后对照（实测）

| 场景（旧情节 floor1 `1919-11-20 08:00 码头`；新情节 floor2 `— 深夜 酒馆`） | 修复前 | 修复后 |
| --- | --- | --- |
| 新情节只有「时间/地点」 | `1919-11-20 / 08:00 / 码头` ❌ | `1919-11-20 / 深夜 / 酒馆` ✅ |
| 全部情节都没有日期（只有 `深夜 酒馆`） | 全空 ❌（时间也没拿到） | `— / 深夜 / 酒馆` ✅ |
| 总览显示 | 灰字「（参考最近情节：深夜）」+ 旧时间 | 「⏱ 时间：深夜」（实值） ✅ |
| 无楼层信息的新情节（导入旧数据） | 取不到 ❌ | 按剧情日期取到 ✅ |
| 两边都有楼层（旧情节 floor 18 日期旧、新情节 floor 2 日期新） | 楼层优先 → 取 floor 18 | **不变**（楼层优先，原口径） |

## 6. 边界（有意保留）

| 项 | 口径 |
| --- | --- |
| 「最新」的定义 | 情节内**楼层最新**（两边都有楼层信息时）；无楼层信息时用剧情日期 —— 与 v2.51.0 契约一致，未改成「日期优先」以免 AI 写错的未来日期劫持时钟 |
| 逐字段拼接 | 允许「日期来自较早那条、时间来自最新那条」（这正是用户要的「从最新情节抓取」）；跨条拼接时追踪里明确标注 |
| 非情节来源 | 记忆 / 角色 / 物品 / 场景 / 状态 / 传言之类**仍然完全不参与**时钟取值（v2.51.0 契约不变） |
