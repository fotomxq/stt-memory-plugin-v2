## 1. 图展示样式（`ui/scene-map-graph.js`）

| 面 | v3.50.6（首版） | **v3.50.9（美化）** |
| --- | --- | --- |
| 布局 | 按层级分列、层内按输入顺序下排（父节点与子块**不对齐**） | **整齐树（tidy layering）**：同一父节点的子节点**成组垂直居中**在父旁 → 连线不交叉、不用力导向也整齐 |
| 节点尺寸 | 固定 118 宽，长名称**溢出** | **宽度随文字自适应**（夹 96–176），过长**截断加「…」**（`mapTextWidth` 确定性估宽，可单测） |
| 边 | 中心直连 `<line>` | **节点边框出入点 + 贝塞尔曲线**（父右出 / 子左入；同层走上下弧）+ **箭头 marker**（有向） |
| 边标签 | 一行小字压在线上 | **两行标签片**（名称 → 名称 / 度量），带**底色圆角小片**，压在曲线上也读得清 |
| 视觉分件 | 只有圆角矩形 | **defs**（两枚箭头 marker + `feDropShadow` 阴影）· 节点卡片 + **左侧层级色条**（场景蓝 / 房间中性 / 陈设青）· 悬停抬升（`fill` + `stroke` 过渡） |
| 图例 | 一行文字 | 图例带**计数**（走过 N / 未走过 M）+ 从属线样式 + 「点节点下钻 / 插入套话」提示 |
| 确定性 | 同一份数据同图 | **保持**：无随机、无物理引擎、无时间依赖；SVG id 前缀由尺寸推导（同页多图不冲突） |

## 2. 展示样式（`ui/scene-map.js` + `style.css`）

- **顶栏统计胶囊**：`🏠 单元` / `🧭 路径` / `👣 剧情走过`（走过时为绿色）/ `📦 上限` —— 一眼看到规模与「有多少是剧情真走过的」；
- **网图独立卡片**：`🕸 网状图` 小标题 + 外框（圆角 / 细边），与下方明细列表视觉分层；
- **面包屑胶囊化**：层级用 `›` 分隔，当前层加胶囊底（`ftt-map-cur`）；
- **分节标题统一装饰类** `ftt-map-h4`（网状图 / 房间 / 场所 / 陈设）；
- **说明更明确**：补「**点图中的节点**即可下钻或插入套话」。

## 4. 如实登记（未做 / 限制）

1. 布局是**整齐树 + 分层**，未做力导向 / 环形 / 正交布线等他类美学（同场景数据量小，整齐树最易读且**确定可测**）；
2. **未做交互增强**（拖拽 / 缩放 / 悬停高亮整条路径 / 双击居中）——面板既有动作分发只认点击；
3. 节点宽度用**确定性估算**（中日韩 1 字宽 / 其余 0.55）而非真实测量（SVG 内无测量 API，保持纯函数可测）；
4. **真机未人工试用**：需刷新后在「场景 → 🗺 地图」看网图与统计胶囊。
