## 1. 字段与三级口径

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `nsfw` | `none`（无）· `weak`（弱）· `strong`（强） | **原子数据**（情节 / 状态记录 / 角色档案 / 长期记忆 / 物品 / 计划 / 悬念 / 场景 / 概念 / 平行事件 / 传言 / 情节分段）每条一个标签 |

- **无** = 与 NSFW 完全无关；**弱** = 有部分亲密或暗示但无露骨内容；**强** = 完全是露骨内容。
- 字段缺省 = **无**（不写盘：绝大多数条目无关，不为此给每条数据加噪声）；`nsfw` **不参与内容哈希**
  （`core/model/hashfields.js#HASH_FIELDS` 未收录），因此不影响去重、瘦身与跨端对账；瘦身写盘按「非默认值保留」原样带上（`core/slim.js`）。
- 纯函数实现：`core/nsfw-level.js`（等级归一 / 取高 / 弱级信号 / 打标），**无任何宿主或 state 依赖**，可被低层模块安全引用。

## 2. 判级：写入当时的事实

```text
nsfwStampLevel(条目, 本次判级) = max(既有留档, AI 显式标注, 按原文判级)
```

| 来源 | 规则 |
| --- | --- |
| AI 显式标注 | delta 里的 `nsfw` / `NSFW` / `露骨程度` / `NSFW等级` / `nsfwLevel`（值认 `无/弱/强`、`none/weak/strong`、`0/1/2`） |
| 按原文判级 | 命中**识别词条库**（`cfg.nsfwKeywords`，默认内置 63 条）→ `strong`；仅命中**弱级信号词**（内置 33 条：亲近/拥抱/亲吻/缠绵/暧昧/调戏…＋英文整词）→ `weak`；都没有 → `none` |
| 判级范围 | 与弱化同一套字段白名单（`NSFW_FIELD_MAP`）：例如情节 `title/text/content`、状态记录 `subject/value`、记忆 `title/content`；货币/名册不在其列 |

**打标位置**（所有写法统一走 `core/entry-meta.js#preserveEntryMeta`）：AI 增量落库（`mergeDelta` 全部维度 + 情节新增/更新）、
手动新增与编辑（`upsertEntry`）、载入补档（`nsfwBackfill`，老存档与派生条目各补一次）。
**只升不降**：一旦记为「强」，之后无论弱化、AI 改写、重归一化、同内容去重还是跨端合并，都不会降回「弱/无」。

## 3. 永久性留档：弱化不改标签

弱化的两条路径（`nsfwFixedReplace` 固定规则机械替换 / `applyNsfwSoftenResult` AI 弱化）**只写文本字段**
（含镜像字段同步与 `updatedAt`），**绝不触碰 `nsfw`**；提示词里还会带上该条目的「留档等级」供 AI 参考。

```text
原文「强」 → 弱化为「亲近/相拥」 → 条目文本已不露骨（再判级只会得到「弱」）
                                    → 但 nsfw 仍为「strong」（取高 + 路径不写标签）
```

跨端与去重同样取高：`mergeDataObjects` 胜出条目继承另一侧的等级；`contentDedupeArray` 合并副本时取高。

## 4. 修 V1 移植缺陷：状态记录维度此前整维被跳过（有意偏离 V1）

- 事实：`NSFW_FIELD_MAP` 用维度键 `states`（= 状态记录），而状态容器在 state 上叫 `currentStates`。
  弱化模块照抄 V1 的 `state[dim]` 取值 → `state.states` 恒为空 → **状态记录从来没有被 NSFW 扫描/弱化过**（V1 亦然）。
- 修正：新增 `nsfwDimList(dim)`，一律经 `core/config.js#KIND_MAP` 解析真实容器（`states → currentStates`）。
- 影响：`nsfwScan` / `nsfwSoftenPack` / `nsfwFixedReplace` / `applyNsfwSoftenResult` / 等级统计与补档都覆盖状态记录。
- 黄金样本口径不变：V1 样本场景里 `currentStates` 为空，故 `H7/H8/H13/H14` 的计数与逐字比较仍然成立；
  该偏离由 `tests/unit/nsfw-level.test.js#D1` 单独锁死（**有意偏离 V1**，与 `P10c9` 的调试日志单条上限同类登记）。

## 7. 兼容与回退 / 风险

- **兼容**：老存档没有该字段 → 行为与 v3.7.0 完全一致（不显示徽标、不判级）；载入时**自动补档一次**
  （按现存正文判级，只升不降，文本没有命中就不写盘）。
  注意：补档只能依据**现存正文** —— 若正文在 v3.8.0 之前已被弱化，补出来的等级会是「弱」而非当年的「强」（历史不可考）；
  v3.8.0 起写入的数据不受此影响。
- **回退**：字段不参与内容哈希与注入，删掉它不影响任何既有行为。
- **风险（误报方向）**：弱级信号是词面判据，「拥抱 / 亲近」一类在普通叙事里也会出现 → 可能偏保守地记为「弱」。
  误报方向是**多打标**（只在列表行多一个徽标），不会影响注入与召回；强级判据与弱化功能共用同一套词库，口径一致。
