## 1. 需求落定（把用户那句话拆成可核对的四条）

| 用户原话 | 落定口径 |
| --- | --- |
| 「抽取分析**被标记为强NSFW**的原子数据」 | 只取 `entry.nsfw === 'strong'` 的条目文本字段（维度/字段白名单与弱化共用 `NSFW_FIELD_MAP`）；已总结隐藏的情节不参与；过短（<8 字）字段跳过 |
| 「交给AI去**识别哪些词汇涉及到强NSFW**」 | AI 从原文里**原样摘出**造成露骨的词（不造词、不改写）；「词」必须能在本次提交的原文里找到（删后逐条核对，找不到即丢弃） |
| 「以及应该**替换**成什么词汇」 | 每个词给出一个柔化替换词 + 一句话理由（`理由` 存进账本明细，便于事后核对 AI 的判断） |
| 「最后输出**保存到转化库**，用于后续弱化NSFW使用」 | 写入**转化库**（`cfg.nsfwRules`，立刻可被「🔁 立即固定规则替换」与弱化流程使用）；同一批词**补进识别词条库**（`cfg.nsfwKeywords`），使后续扫描与留档判级也能识别它们 |

## 2. 流程

```text
设定 → NSFW弱化 → 🧠 词条分析
  ├─ 抽取：留档为「强」的字段（每批 12 处；只提交**未分析过**的，指纹表上限 300）
  ├─ 提示词：模板 `nsfwAnalyze`（提示词面板「④ 质检维护」可改）→ aiCallText（进管线状态）
  ├─ 解析：extractJsonObject → {"词条":[{编号,词,替换,理由}], "无法处理":[…]}
  ├─ 校验：见 §3（每条丢弃都带原因）
  ├─ 落库：nsfwRuleAdd(词,替换) → 转化库；nsfwKeywordAdd(词) → 识别词条库；saveCfg()
  └─ 记账：nsfwAnalyzeLog（最近一次结果 + 最近 10 条明细 + 指纹）；dbgLog 一条；toast 摘要
```

进度语义：**已提交过的字段按内容指纹记账**（`dim|id|path|hash(文本)`），所以反复点按钮会持续推进；
强留档字段全部分析过后**不再调用 AI**（省 token），页面给出「♻ 重置分析进度」；正文被改写后指纹变化 → 自动重新入队。

## 3. 校验表（丢弃原因一览，全部在提示里如实回报）

| 原因 | 判据 | 设计理由 |
| --- | --- | --- |
| `not-in-text` | 词不在本次提交的原文里 | 防 AI 造词 / 给近义词（那样机械替换会替换不到任何东西） |
| `to-still-nsfw` | 替换词命中识别词条库 | 防「换成另一个露骨词」 |
| `to-contains-term` / `same` | 替换词包含原词 / 相同 | 替换无意义或会自我触发 |
| `term-too-short` | 中文 1 字 / 拉丁 <3 字母 | 单字词（乳 / 臀 / 操）机械替换误伤极大 |
| `term-too-long` / `to-too-long` | 词 >20 / 替换 >30 字 | 保证规则库可读、替换后不膨胀 |
| `bad-chars` / `to-bad-chars` | 含空白、标点或正则元字符 | 规则库是按字面匹配的（英文走 `\b词\w*`），不接受正则雷区 |
| `blocklist` | 命中日常词黑名单（60 余条：身体 / 眼睛 / 房间 / kiss / body …） | AI 常把"氛围词"当涉敏词提出来 |
| `dup-library` / `dup-batch` | 已在库 / 同批重复 | 正常去重（单独计数，不算"不合格"） |
| **`wide-use`** | 词在**非强留档**数据里出现 **≥5 条**（最多扫 400 条） | **误伤护栏**：一个词若在大量非露骨数据里出现，它必然是日常词 —— 落库会全库误替换 |
| `capped` | 单次超过 40 条 | 防一次刷爆转化库 |

## 4. 顺带修复（同一处代码的老问题）

| 问题 | 现状 | 处置 |
| --- | --- | --- |
| 词条库 / 转化库编辑**不落盘** | `ui/nsfw.js` 只改 `cfg`，从不 `saveCfg()` → 重开面板/重载页面改动丢失 | 各库动作成功后 `persistCfg()`（`saveCfg()`） |

## 6. 未验证项（如实登记）

- **真机待刷新核对**：页面当前仍是 v3.17.1 之前的版本；刷新后应看到「🧠 词条分析」分节、状态行与两个按钮；
- **产词质量取决于模型**：模板默认文案本轮首次给出（强调"词必须原样出现 + 不要日常词 + 每条最多 6 个"），若某模型产词偏少/偏多，可直接在提示词面板改 `nsfwAnalyze` 模板；
- **阈值是拍定值**：误伤护栏 5 条、单次上限 40 条、每批 12 处 —— 若真机出现「好词被拦」或「一次落库过多」，按本档 §3 调整并记新批次；
- **不自动弱化**：本功能只**建规则**，不改任何正文；要真正替换正文需点「🔁 立即固定规则替换」（或让弱化流程先跑固定规则）。
