# P10m · 导出下载文件 / 导入存档文件（v2.49.0）

> 文档版本：v1.0 ｜ 日期：2026-09-26 ｜ 状态：生效（v2.49.0）
> 触发（用户原话）：「**导出和导入，应该正确触发导出及下载文件，以及导入存档文件。该机制存在问题。**」
> 涉及：`ui/file-io.js`（新） · `ui/panel.js`（`exportState` / `importStateOpen` 动作） · `ui/settings-pages.js`（数据管理页文案）
> · `index.js`（`exportFileName` 钩子） · `tests/unit/file-io.test.js`（新） · `tests/smoke-test.js`（AY1）

---

## 1. 问题定性

V2 的数据管理页此前只做了「半个」导出/导入：

| 动作 | V2 旧行为 | V1 真实行为（v1.206） |
| --- | --- | --- |
| 「⬇ 导出 JSON」 | 把 JSON 放进文本框 + 写剪贴板 —— **不落文件** | `new Blob([json],{type:'application/json'})` → `URL.createObjectURL` → `<a download="FTT记忆_<hash>.json">` → `click()`（27048/27214） |
| 「⬆ 导入 JSON」 | 只提示「去文本框粘贴」 —— **不弹文件选择器** | `<input type="file" accept=".json">` → `FileReader.readAsText` → 增量合并（27058/26218、27226） |

于是用户看到的是：点导出没有任何文件、点导入无法选存档 —— 即「该机制存在问题」。

## 2. 修复

- 新增 `ui/file-io.js`（只做 IO、不碰业务）：
  - `downloadTextFile(filename, text, mime)`：**Blob + `URL.createObjectURL` + `<a download>` + `click()`**，
    节点用完即移除、URL **延迟 5 秒回收**（V1 同款；太早回收会让部分宿主下载失败）；
  - `pickTextFile({accept,timeoutMs})`：`<input type=file>` + `click()`，`onchange` 读文件（优先 `file.text()`，
    回落 `FileReader.readAsText` —— V1 用的就是后者），`oncancel`/超时（默认 120s）返回 `cancelled`；
  - `fileIoCapabilities()`：宿主能力探测；**一切失败都返回 `{ok:false,reason}`，永不抛**。
- `ui/panel.js`：
  - `exportState`：导出文本 → **真实下载**（文件名经新钩子 `exportFileName()`，V1 口径 `FTT记忆_<角色哈希>.json`）
    → 仍复制剪贴板 → 文本框保留；note 明确写「已下载文件 X」或「未下载文件（原因，可手动复制保存）」。
  - `importStateOpen`：**弹出文件选择器**（V1 同款按钮语义）→ 读取 → `hooks.importState(text)` 增量合并 →
    note 报「已导入文件 X 并合并：新增 N 条」；取消/无选择器时提示仍可走文本框粘贴。
  - 文本框路径（`importStateApply`）**保留**：`[data-ftt-import]` 粘贴 → 「⬆ 导入」。
- `ui/settings-pages.js`：按钮文案与 title 对齐 V1（`⬆ 导入 JSON（合并）` + 「增量导入：按原子内容哈希差异化合并…」），
  文本框标签注明「上方按钮可直接选文件，也可在此粘贴」。
- `index.js`：新增面板钩子 `exportFileName`（`hashText(scopeKey)`，与 V1 同算法同命名）。

| 冒烟 **AY1** | 真实面板 + 真实点击委托：导出产生 `blob:` 锚点且 `download` 形如 `FTT记忆_<hash>.json`、note 含「已下载文件」；导入弹出 `input[type=file][accept*=json]`、读取「冒烟存档.json」并完成合并（note 含「已导入文件 冒烟存档.json」） |

**注意（宿主差异）**：Tauri 等原生宿主可能既无 `Blob`/`URL.createObjectURL`、也无文件选择器 —— 这两种情况下
面板**不会静默失败**：导出提示「未下载文件（no-download…）并保留文本框」，导入提示「不支持文件选择器 → 请在文本框粘贴」。
