## 1. 范围与做法

沿用 v3.10.0 的**加法式**扩充：V1 的 63 条与 v3.10.0 的 81 条**一字不动**，新词条一律排在后面。

```text

NSFW_KEYWORDS_V310 = v3.10.0 追加 81 条（不变）
NSFW_KEYWORDS_V312 = v3.12.0 追加 185 条（新：生僻 122 条 + 英文 63 条）
NSFW_KEYWORDS      = 63 + 81 + 185 = 329 条
NSFW_RULES         = 由词条库派生（逐条对应） = 329 条
```

替换引擎（`nsfwApplyRules`）**未改动**：仍是「原文单遍匹配 + 区间占位、长词优先、不链式」；
新增词条只影响「哪些字面会被认出来」，不改变既有字面的替换结果（由单测 G5 逐字锁死）。

## 4. 选词口径（**故意不收**哪些词）

内置中文匹配是 `indexOf`（子串），英文匹配是 `\b词首 + \w*`。因此命中越"宽"越容易误伤普通叙事，
本版坚持**多字词优先**，并主动排除下列候选（它们在日常文本里高频，替换后会把正常句子改坏）：

| 未收录 | 原因（普通语境反例） |
| --- | --- |
| 折磨 / 侮辱 / 操弄 | 「被病痛折磨」「言语侮辱」「操弄舆论」——普通叙事极高频 |
| 狂干 / 狠干 / 猛操 / 爆操 | 「狂干活」「狠干活」「猛操作」——`干/操` 后接动词普遍 |
| 挺入 / 上垒 | 「挺入决赛」「棒球上垒」 |
| 白浊 | 「白浊的河水」 |
| 母畜 / 肉畜 / 便器 | 「母畜养殖」「肉畜出栏」「陶瓷便器」 |
| 触手（只收 `触手系`） | 「触手可及」——成语 |
| 后庭 / 玉门 / 花径 / 幽谷 / 落红 / 见红 / 玉柱 / 玄关 | 地名、诗词、园林、医学与日常义并存（如「玉门关」「落红不是无情物」「孕妇见红」） |
| 淫雨 / 淫威 / 淫祀 / 淫逸 | 古汉语里 `淫` 可作「过度/失度」，非性语义 |
| 单字（屌 / 尻 / 干 …）与短英文（sm / anal / sex / ero / rape） | 单字误伤面过大；`anal→analysis`、`rape→rapeseed`、`sex→sexton`、`ero→erosion`；`rape` 故只收 `rapist / raping / raped` |
| yuri | 与常见人名 `Yuri` 冲突（`yaoi` 无此问题，收） |

## 9. 存量影响面实测（真实落盘状态 · 离线只读复算）

| 实际命中的新词条种类 | **7 种**：`屈辱` 5 · `凌辱` 3 · `皮鞭` 2 · `虐待` 1 · `爱液` 1 · `催情` 1 · `受虐` 1 |

**结论**：
- 真正被用上的是**束缚 / 凌辱 / 重口味**那一组（正是用户点名的方向），§5 误伤登记表里的
  `项圈 / 失禁 / 交尾 / 口活 / 会阴 / 鼠蹊` **一条都没有命中** —— 本档语料里没有这些跨语境用法；
- `屈辱`（5 条）与 `凌辱`（3 条）是**唯一需要盯**的两个词：它们在非情色叙事（霸凌 / 战争 / 职场）里同样成立，
  但在不阅读正文的前提下无法判定本档这些命中是否属于误伤 —— 如实留在这里，等用户按需反馈后再决定是否收窄；
- 未命中 ≠ 无用：新词条只在**下一次弱化/识别运行时**对存量条目生效（**不主动回填**，与 v3.10.0 一致）。
