## 1. 提示组件的三条通道（`ui/hints.js`）

| 通道 | 函数 | 用途 | 落点 |
| --- | --- | --- | --- |
| 一句话 | `shortHintHtml(text)` | 页面上**唯一**的说明行（≤ 40 字，带 `data-ftt-short-hint`） | 每节 / 每页首行 |
| 折叠说明 | `hintDetailsHtml(summary, body)` | 详细解释，默认收起；触屏可点开、不占版面 | `<details class="ftt-details ftt-hint-details">`「ⓘ 说明 / ⓘ 参数说明」 |
| 悬停提示 | 控件字段 `hint`（`settingsControlHtml` 支持） | 单个参数的默认值 / 含义；标签后带「ⓘ」标记 | `title="…"`（桌面悬停即见） |
| 参数清单 | `paramListHtml(controls)` | 「参数含义」列表，**由控件 `hint` 自动生成** | 折叠说明内，避免两处维护 |

### 传言（新增 `rumorsPageHtml`）

- 页首一句：「传言：记录 → 按剧情轮次演化 → 注入；发酵到阈值可裂变。」

  `每隔 N 楼轮次演化一次（默认 5）` → `演化间隔（楼）`；`单次变化过程所需轮次（默认 2，变化不会立刻生效）` → `演化所需轮次`；
  `触发裂变的最低发酵度（默认 80）` → `裂变发酵度`；`裂变 / 变异概率（0-1，默认 0.3）` → `裂变 / 变异概率`；
  `与平行事件联动的标签关联阈值（默认 0.34）` → `平行联动相似度`；`联动概率（0-1，默认 0.35）` → `平行联动概率`；

## 4. 未验证 / 风险

1. `<details>` 折叠块依赖酒馆面板内的原生支持（所有现代浏览器均支持）；真实浏览器观感未实测（本机无运行时）。
2. 悬停提示（`title`）在触屏设备上不可见 —— 因此**关键信息（默认值/含义）同时放进了折叠块**，两者同源。
3. 参数清单只收录带 `hint` 的控件；后续给新控件补 `hint` 时会自动出现在折叠块里。
