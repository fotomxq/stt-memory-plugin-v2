# P10c151 · 内存核查：长期收支两处无界增长（v3.51.10）

> 文档版本：v1.0 ｜ 日期：2026-10-25 ｜ 状态：生效（v3.51.10）
> 用户要求（原话）：「最近5轮更新可能引入了内存泄漏BUG，请核对修复。」
> 关联：`core/model/deal.js#DEAL_NODES_MAX / #capDealNodes` · `core/deal-triggers.js` · `ui/money-tabs.js#LEDGER_RENDER_MAX`

## 1. 核对方法（先测，再改）

1. **动作/渲染 soak**：mock 环境连续 800 次「打开编辑器 → 取消 → 切子页」，用 `--expose-gc` 量 `heapUsed`。
   首轮测到 +34MB —— 追查为**测试桩自身** `insertAdjacentHTML` 把整页 HTML 拼接到 `el.html`（`+=`）导致的历史累积，
   清掉桩的 `html`/`__qs` 后同样 800 次仅 **+1.28MB**（trace/debug 环形缓冲填到上限），**插件层无每次动作的泄漏**；
2. **入库 soak**：1500 次 `mergeDelta`（含货币/物品）→ +0.94MB（`items` 被上限裁剪、`currencies[].history` 上限 60 生效），无泄漏；
3. 逐项检查 v3.51.5–v3.51.9 新增代码（`entry-flat` / `node-table-dom` / `deal-repair` / `deal-triggers` / `money-tabs`）：
   均无模块级累加器、无重复监听（`bindOverlay` 有 `__fttBound`、滑动行 `WeakSet`）、无未清定时器（`pipelineTimer` / `bridgeTimer` 单槽 + 离页即停）；
4. **找到两处真实的无界增长**（不是"泄漏"式的对象图，而是**长期只增的数组**，长跑后同样表现为内存/体积持续上涨）：

## 2. 缺陷一：`deals[].outlook.nodes` 无上限

v3.51.5 起「抵达即触发 + 跨周期叠加」+ v3.51.8「修复按钮先全量结算」，使得**每次日期推进都可能追加节点**，
而旧实现**没有任何上限** → 长跑（月度条目按年推进）后单条标的物的节点可无限增长，直接体现在存档体积与详情渲染。

**修复**（`core/model/deal.js`）：

* 新增 `DEAL_NODES_MAX = 240` 与 `capDealNodes(nodes)`（按日期排序后保留最近 240 条）；
* `normalizeDeal` 归一即裁剪；`runDealTriggers` 每次追加后与收尾各裁一次（含零金额推进的节点）；
* `lastChangeDate` 由**保留段**的最后一条维护（节点是"展示/派生"，权威流水在 `ledger` —— `ledger` 仍**长期只增**，符合 `D28`）。

## 3. 缺陷二：收支记录页一次性渲染**全部**流水

v3.51.3 起收支记录页直接 `all.map(...)`，而账本按设计长期只增 → 长跑后**每次渲染**都要拼一份越来越大的 HTML（内存与耗时双涨）。

**修复**（`ui/money-tabs.js`）：`LEDGER_RENDER_MAX = 200` —— 列表只渲染最近 200 笔，页脚如实标注「共 N 笔，此处显示最近 200 笔」
（合计卡仍按**全量**计算）；更早的记录仍在账本里（可导出/后续分页查看）。

## 4. 测试

`tests/unit/deal-forecast-fallback.test.js` 21 → **24 项**：
* H1 归一裁剪（300 → 240，`lastChangeDate` 取保留段末条）；
* H2 触发器长跑（> 240 个周期）：节点恰好 240、**账本全量**（> 240）——「节点有上界、流水不丢」；
* H3 收支记录页渲染上限（260 笔 → 渲染 200 行 + 页脚总计 260 + 合计按全量）。

全量单测 **259 文件 / 3856 断言**；冒烟 224 项；`npm run gate` 全绿。

## 5. 边界

1. 节点裁剪只砍**最早**的（不重排、不改内容）；被裁的节点对应的流水**仍在 `ledger`**（可导出核对）；
2. 账本本身**不裁剪**（`D28` 语义数据不自动移除）；界面渲染有界、数据结构如实保留；
3. 本版不改任何数据契约，老存档的 `nodes` 会在下次归一（载入/保存/修复）时被裁到 240。
