## 1. 改动前的三种行为（逐条核对过代码）

| 入口 | 改动前行为 | 落点 |
| --- | --- | --- |
| 批量摘要（⚡ 立即 AI 摘要；`silent` 自动补全） | **会**分段：段长 = `cfg.summaryChunkSize`，**默认 10 楼/段** | `host/extract.js#runAutoSummary` → `buildSegments` |
| 多楼 / 全量提取（`/ftt-analyze` 无参、面板「提取」回落路径） | **一楼一次 AI 调用** | `host/extract.js#analyzeFloors` → `analyzeFloor` |
| 推演世界（🧭 推演世界） | **一次请求把整个区间正文塞进一个提示词**（手动入口按 `feedFloors`，缺省区间可到 `summaryFloors` = 30） | `core/parallel.js#runParallelWeave` |

同一条「避免一次性分析记忆」的诉求，在三个入口上是三种行为 —— 这是本批要收敛的对象。

## 2. 落定口径

| 结论 | 口径 | 落点 |
| --- | --- | --- |
| 默认段长 = **3 个正文** | `SUMMARY_CHUNK_DEFAULT = 3` 为**唯一事实源**；`defaultCfg.summaryChunkSize` 由它派生（10 → 3） | `core/chunk.js` · `core/config.js` |
| 段内必须连续 | `chunkFloorIds` 先按「连续」断开再切片：`[1,2,3,7,8]` + 3 → `[1-3]`、`[7-8]` | 同左 |
| 段长只作上界 | 末段收口；非法值（`0` / 负数 / `NaN` / `Infinity` / 空串 / 非数字 / 布尔 / 对象）回落：入参 → `cfg` → 默认 3；上限 200 | 同左 |
| 一段 = 一次 AI 请求 | 三个入口一致 | `host/extract.js` · `core/parallel.js` |
| 单楼不倒退 | `analyzeFloors` 只给一个楼层 → 仍走 `analyzeFloor`（提示词 / 台账 / `via='floor'` / 返回形状一字不变） | `host/extract.js` |
| 修复类不动 | 角色 / 状态 / 物品 / 计划 / 场景 / 概念 / 传言 / 分组不走本口径 | 未改 |

## 3. 新增/改动清单

| 文件 | 改动 |

| `core/chunk.js` | **新增**（内核纯函数、零依赖）：`SUMMARY_CHUNK_DEFAULT` / `normalizeChunkSize` / `chunkFloorRange` / `chunkFloorIds` / `chunkInfo` |

| `ui/panel.js` | 推演入口改走分段入口并回报段数；批次行**两种 `range` 形态都认**（生产侧是字符串 `'4-9'`，旧代码按对象读 → 「第 N-M 楼」从来没显示过）+ 显示「每段 ≤N 个正文」；提示与通知补段长 |

| `ui/debug.js` | 新增只读桥方法 **`ftt.chunkPlan`**（生效段长 / 是否内置默认 / 未摘要段数 + 前 5 段预览 / 上一批实际段数） |
