## 2. `技-48`：AI 聚合器（✓ 内核侧完成）

新增 **`core/repair-aggregate.js`**（纯内核，AI/落盘走注入钩子 → 可单测）：

| 导出 | 作用 |
| --- | --- |
| `buildAggregatePrompt({domains,picks,budget})` | 逐域 `pick → buildSection`，拼成 `## <中文名>（<aggKey>）` **分节** + 按域分键的 JSON 契约；`maxChars` 超限**截断**并标记 `truncated` |
| `aggDomains(budget)` | 参与域（**结构类 → 混合类 → 文本类**；受 `maxDomains` 限制） |
| `splitAggregateResult(delta, sections)` | 按 `aggKey` 拆回域；缺席进 `missing` |
| `applyAggregate({byDomain,domains,applyOne})` | **结构先、文本后**；**域级隔离**（某域抛错只跳过该域） |
| `runRepairAggregate(opts)` | 编排：一次请求 → 解析 → 拆回 → 应用 → **坏 JSON 按域降级** → 仍失败**零写入** → 写一条日志 |
| `parseAggJson(raw)` | 宽松解析（裸 JSON / 代码围栏 / 前后杂字） |
| `aggCounters(init)` | 四项计数：**截断 `truncated` · 缺失 `missing` · 跳过 `skipped` · 降级 `degraded`** |

**总开关**：`cfg.repairAggEnabled = false` → `runRepairAggregate` 直接返回 `{disabled:true}`（**不发请求**，调用方回退各域单发，既有路径不变）。
