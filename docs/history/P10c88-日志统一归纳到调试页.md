| 片段 | 落点 |

## 2. 改了什么（位置变了，数据与动作零改动）

| # | 落点 | 改动 |
| --- | --- | --- |
| ① | `ui/sync.js#storagePageHtml` | ①「📋 最近记录」整块**删除**；②「🔄 同步日志（最近 30 条 · 本角色）」整节**删除**（含服务端状态行与刷新 / 清空两个按钮）；③ 新增**一行指路**的小节「日志与留痕」：`调试日志 · 记录（无需确认）· 同步日志统一在 设定 → 调试 → 📋 日志 查看与清理（本页不再重复列出）`；④ 仍留在存储页的只有「⚠️ 待确认」——它**不是日志**（需要人做决定，带差异化动作） |
| ② | `ui/debug.js#debugPageHtml` | 在「📋 日志」之后**新增两节**：`📋 记录（N 类 · 共 M 次 · 无需确认）`（无记录时给空态一行，保证「记录」有唯一可见去处）与 `🔄 同步日志（最近 30 条 · 本角色）`（服务端状态行 + `🔄 刷新日志（与服务端合并）` + `🧹 清空日志` + 列表）。数据与实现**全部复用原出口**（`core/conflicts.js#listConflictLog/conflictLogCount`、`ui/sync.js#syncLogHtml/syncLogServerStatusHtml`），**没有一处重算** |
| ③ | 动作与锚点 | 动作名不变（`syncLogRefresh` / `syncLogClear`）→ 面板分发按**动作名**路由（与所在页无关），按钮换页后照常可用；锚点不变（`data-ftt-sync-log` / `data-ftt-sync-log-status` / `data-ftt-conflict-log` / `data-ftt-conflict-log-row="<id>"`）→ 外部核对与测试锚点稳定 |
| ④ | 提示语 | `syncAction('resolveConflicts')` 的批量确认提示由「…；最近记录仍有 N 类（无需确认）」改为「…；**记录区**仍有 N 类（无需确认，见 设定 → 调试 → 📋 日志）」 |

**有意偏离 V1（`开发守则.md` §2.4 类别②）**：V1 把同步日志列在**存储页**（V2 的 `storagePageHtml` 一直照此对齐，见 `docs/history/P8i-B7-2跨端同步.md` §3）。
本版按**用户当轮明确要求**（用户要求 > `docs` > V1）改为统一收到**调试页日志区**；数据模型、`core/sync-log.js` 环形与上限（30）、服务端镜像逻辑**一字未动**。
登记位置：`docs/04` 附录 + 本档 + `CHANGELOG.md` v3.45.8。
