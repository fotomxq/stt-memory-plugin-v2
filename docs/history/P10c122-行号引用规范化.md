## 1. 缺陷（`docs/D21` §8 `技-17`）

文档里的源码引用写成**绝对行号**（`core/ingest.js:1355`）—— 行号会随任何一次代码改动漂移，而文档不会自动跟着走，
读者被指向错误的位置。口径（`docs/14` C9 / `开发守则` §2.3）：新引用一律写 `文件#符号`，存量**只减不增**（棘轮）。

**本轮前实测**：101 处绝对行号 + 1671 处 `文件#符号`。

## 2. 修法

用**顶层声明定位**把绝对行号批量改成 `文件#符号`（**不用正则猜名字**：按行号向上找最近的**列 0** 顶层
`export function/const/class` 或 `function/const/class`，并校验该标识符在该文件里真实存在）：

| 文档 | 转换处数 |
| --- | --- |
| `docs/D7-重要度动态计算设计稿.md` | 49 → 0 |
| `docs/D13-存储层级与界面成本上限核对.md` | 22 → 0 |
| `docs/D8-内容哈希与瘦身白名单设计稿.md` | 22 → 0 |
| `docs/D10-TauriTavern兼容与存储简化设计稿.md` | 3 → 0 |
| `docs/D9-UI统一规范设计稿.md` | 3 → 0 |
| `docs/D12-楼层骤减的数据安全与删除操作设计稿.md` | 2 → 0 |
| `docs/D4-原子关系层联动设计稿.md` | 1 → **保留** |

**实测**：绝对行号 **101 → 1**，`文件#符号` **1671 → 1771**（全部可解析，C8 绿）。

**保留的那 1 处**：`docs/D4` 引用的是 `host/extract.js` 的**头部注释**（`11-12` 行）—— 它描述的是「文件开头的
注释块」而不是某个符号，改成 `#某函数` 会**失真**，故保留并在预算历史里写明（棘轮 1 仍「只减不增」）。
