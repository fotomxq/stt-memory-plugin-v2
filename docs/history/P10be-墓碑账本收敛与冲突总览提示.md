## 2. `core/conflicts.js` 口径

- 只登记**需要人管**的事（跨端合并冲突 / 并集自检异常 / 快照覆盖面缩小…），**不叫「错误」**（错误仍走 `warn`/异常通道）；
- 按 `kind + detail` 去重、累加 `count`、记录 `firstAt/lastAt`；**上限 50 条**（同毫秒插入按 `seq` 保证「最新在前」，裁剪掉最早那批）；
- 处理动作只有两种语义：**标记已确认**（人看过了）与**清空**；**不做自动修复**（合并一律并集、按时间取新，宁可多留）；
- 持久化经注入钩子落 **ST 扩展设置 `syncConflicts`**——**不进数据模型，`DATA_VERSION` 保持 1**。
