# P10d · 点击不跳顶（滚动位置保持）· 对齐 V1 修复（v2.38.0）

> 文档版本：v1.0 ｜ 日期：2026-09-26 ｜ 状态：生效（v2.38.0）
> 触发（用户原话）：「**按钮点击不能突然置顶，之前 V1 修复过该问题。V2 请对齐，点击后不能跳顶。**」
> 涉及：`ui/panel.js` · `tests/unit/panel-scroll.test.js` · `tests/smoke-test.js`

---

## 1. V1 当年的修复（事实源，v1.206）

V1 为这个问题做过**四处**修复，V2 此前**一处都没移植**：

| # | V1 位置 | 做法 |
| --- | --- | --- |
| ① | `renderPanel()` 26507~26536 | 重渲染**前**记录滚动位置（`panelEl.scrollTop` + **当前活动标签**的内容区 `.ftt-body[data-ftt-body="<activeTab>"]`），渲染后恢复 |
| ② | 同上，26525 | 渲染后给所有 `<button>` 补 `type="button"` —— 无 `type` 的按钮在 `<form>` 内默认是 **submit** → 提交/刷新 → 页面跳顶 |
| ③ | 切页 26083/26089、切子标签 26166/26171 | 记录 `.ftt-tabs` / `.ftt-subtabs` 的 `scrollLeft` + 面板滚动，`renderPanel()` 后在 `requestAnimationFrame` 里恢复 |
| ④ | 点击入口 26075~26078 | 点在 `button, a, [data-ftt-action]` 上时 `e.preventDefault()` + `e.stopPropagation()`（`<a href="javascript:void(0)">` 与表单提交都不再产生位移） |

V1 源码里的两条**关键注释**（V2 照抄了结论）：

- 「重渲染前记录滚动位置（面板 + 当前内容区），渲染后恢复 —— 点击任意按钮不再"跳回顶部"」；
- 「恢复对象必须是**当前活动标签**的内容区（`.ftt-body[data-ftt-body=activeTab]`；旧实现 `querySelector('.ftt-body')` 恒取第一个 = 总览，**计划悬念页滚动位置没被记录 → 删除后回顶部**）」。

## 2. V2 为什么也在跳

V2 的面板结构与 V1 同构（`#ftt-panel > .ftt-modal > .ftt-tabs + .ftt-body[...]`，滚动容器是 `.ftt-body{overflow-y:auto}`），
且 `panelAction()` **每个动作结尾都会 `renderPanel()`**，而 `renderPanel()` 是 `el.innerHTML = panelHtml()` ——
整棵子树被替换 → 滚动位置归零。叠加两个缺失：

- 面板 HTML 里的 `<button>` **全部没有 `type`**（实测「情节」页 6 个、「设定」页 5 个按钮，`<button(?![^>]*\stype=)` 命中数 = 全部）；
- 点击委托**没有** `preventDefault()`，也没有 V1 的「内层元素 → 父按钮」兜底。

## 3. V2 实现（本批）

```js
// ui/panel.js（v2.38.0）
export function ensureButtonTypes(html)      // 字符串层：<button …> → <button type="button" …>（保留标签大小写）
function hardenButtonTypes(el)               // DOM 层兜底：还没有 type 的按钮补上（V1 等价步骤）
export function panelScrollState(el)         // 捕获 {p(面板), modal, b(活动标签内容区), tabs, subs, tab}
export function applyPanelScroll(el, st)     // 回写（仅在非 0 时写入，不把未滚动容器显式置 0）
function scheduleScrollRestore(el, st)       // requestAnimationFrame 再补一次（字体/图片异步改变高度时）

export function renderPanel() {
    const scroll = panelScrollState(el);              // ① 渲染前捕获
    const html = ensureButtonTypes(panelHtml());      // ② 字符串层补 type="button"
    el.innerHTML = html;
    hardenButtonTypes(el);                            // ③ DOM 层兜底
    applyPanelScroll(el, scroll);                     // ④ 同步恢复
    scheduleScrollRestore(el, scroll);                // ⑤ 布局落定后再补一次
    return html;
}
```

**保留的 V1 关键点**：恢复目标取 `.ftt-body[data-ftt-body="<当前活动标签>"]`（不是第一个 `.ftt-body`）；
只在值非 0 时写入；面板、模态、标签条与子标签条一并处理。

**点击入口**（`bindOverlay` 的 click 委托开头）：

```js
const hit = tg.closest('button, a, [data-ftt-action]');
if (hit) { e.preventDefault(); e.stopPropagation(); }
```

只对 `button / a / [data-ftt-action]` 生效 —— **不动** `<label>`（开关）、`<input>`（勾选/多选）、`<select>` 等原生交互，
避免为了防跳顶把开关点不动（单测 C1 显式断言：`<label>` 上 `preventDefault` **不**被调用）。

**内层元素兜底**（V2 增补，非 V1 原有）：点按钮里的 `<span>/<b>` 时，动作与参数改由
`tg.closest('[data-ftt-action]')` 的 `dataset` 解析（V1 只读 `e.target.dataset`，点内层文字不响应）。参数读取统一走
`ds`，行为对「直接点在按钮上」的既有路径保持不变。

## 4. 与 V1 的差异（本批登记）

| 差异 | 原因 |
| --- | --- |
| 按钮 `type` 在**字符串层**先补一遍（V1 只在 DOM 插入后补） | 无 DOM 解析的宿主（测试桩、受限环境）同样生效；也便于测试与断言 |
| 渲染后追加一次 `requestAnimationFrame` 恢复 | 字体/图片/异步内容改变高度会让同步恢复被浏览器重置；无 rAF 的宿主自动跳过 |
| 内层元素动作兜底 | 见 §3 末（V2 的面板里有 `<span class="ftt-muted">` 等内层节点的按钮） |
| 额外恢复 `.ftt-modal` 的 `scrollTop` | 防御性（V2 的模态 `overflow:hidden`，正常不滚动） |

- `npm run gate` 全绿：单元 **64 文件 / 997 断言**（新增 `tests/unit/panel-scroll.test.js` **8 项**）、
  冒烟 **145 项**（新增 **AO1–AO2**）、内核纯净度 0、内核标识符 0、词条 54、版本一致、文档 0 违规。
- 单测 8 项（含 DOM 影子：`innerHTML=` 会把所有滚动位置**归零**，模拟真实重渲染）：
  - **B1** `ensureButtonTypes`：多按钮 / 带属性 / 大写作 / 自闭合式 全部补齐，已带 `type` 的不动，空输入安全；
    面板真实 HTML（情节页）加固前按钮**全部无 type**、加固后**一个不漏**；
  - **S1** 捕获面板 + 模态 + 标签条 + 子标签条 + **活动标签内容区**（断言取到的是 `plans` 的 321，而不是总览的 999）；
  - **S2** 回写只在非 0 时写入（不把未滚动容器置 0）；
  - **R1/R2** 端到端：重渲染后活动内容区与标签条被恢复；切页后恢复目标随之切换；第一个 `.ftt-body`（总览）不被误写；
  - **R3** 无 `querySelector` 的桩宿主安全（不抛错、HTML 仍写入、按钮 type 已补）；
  - **C1** 点击入口：`button/a/[data-ftt-action]` → `preventDefault + stopPropagation`；`<label>` 与空白处**不拦截**；
  - **C2** 点内层 `<span>` → 解析到父按钮动作（`dimToggle('atoms')`）。
- 冒烟 AO1：`panelHtml()` 加固前按钮 **全部无 type**、`ensureButtonTypes` 与真实 `renderPanel()` 返回值**零漏补**；
  AO2：真实点击（走面板点击委托）→ 重渲染后 `活动内容区 640 / 标签条 37 / 面板 9` 全部保持，
  `preventDefault/stopPropagation` 按监听器数各触发一次，且渲染结果里 `data-ftt-body="atoms"` 与 `type="button"` 均在位。
