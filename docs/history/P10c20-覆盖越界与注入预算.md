## 1. 取证：A3 的真凶是**一个**条目

从宿主原生存储取出主状态文件（1.52 MB，信封 `payload`，台账 12 条），**离线复算**覆盖集合
（与 `core/floor-cover.js` 同口径：`meaningfulFloorRange` → 合并相邻/重叠）：

| 观测 | 值 |
| --- | --- |
| 有效区间总数 | **471** 条（来自各记忆维度条目） |
| 其中越界（端点 > 当前聊天末楼 36） | **1 条** —— 某情节条目 `[1,77]`，且带 `floorNow*`（当前位置字段） |
| 现口径合并结果 | **1 段 `[0,77]` = 78 楼** → 把 37 楼的聊天**全覆盖** |
| 新口径（越界整段忽略） | **4 段 = 20 楼**（`[0,13]` `[20,23]` `[25,25]` `[29,29]`） |

**一条越界区间就足以吞掉整个聊天** —— 因为它与界内区间合并成一段，覆盖判据遂对每一楼都成立。

## 2. A1 是同一根因的后果

逐楼 `ftt.floorDiag(0..36)` 的真实读数：37 楼（19 AI / 18 用户）中只有 12 条台账标记（0,2,…,22），
而 **24/26/28/30/32/34/36 这 7 个 AI 楼无标记、`covered:true`、`wouldBePending:false`**
（`skipped.noText = 0`，不是没正文）。即：**7 个写好的 AI 楼既不出现在未摘要清单，也不会被自动提取处理**。

修后离线复算：这 7 楼在两种口径下的对比如下 ——

| 楼 | 现口径 | 新口径 |
| --- | --- | --- |
| 24 / 26 / 28 / 30 / 32 / 34 / 36 | 覆盖（被跳过） | **不覆盖 → 重新进入待分析** |

## 3. 交付（A1 + A3）

| 位置 | 改动 |
| --- | --- |
| `core/floor-cover.js#floorRanges(st, opts)` | 新增 `opts.maxFloor`：**端点越界的区间整段忽略**（`ignored` 计数）；不夹取 —— 夹取 `[1,77]→[1,36]` 仍会全覆盖，等于没修 |
| `core/floor-cover.js#floorCoverage(st, opts)` | 透传 `maxFloor`，返回增 `ignored` / `maxFloor` |
| `host/floors.js` | 新增导出 `liveFloorTail()`（实时聊天末楼）；`scanPendingFloors` 用 `maxFloor: end`，返回增 `coverIgnored` / `coverMaxFloor` / `coverItems` |
| `ui/debug.js#floorDiag` | 覆盖判定改用 `{ maxFloor: liveFloorTail() }`（诊断与管线**同口径**，不再互相打架） |
| `ui/panel.js` | 总览「已有记忆数据 N 楼」同样限定在本聊天范围 |

> **为什么不改溯源字段**：`floorStart/floorEnd` 与 `floorNow*` 是**证据**（v3.7.0 起「溯源不可变」），
> 修的是**判据**（越界不构成「本聊天该楼已有数据」的证据），不是篡改数据。

## 4. 交付（A2）

`charBudget` 此前只约束召回条目体，**框架完全不计入**。框架组成与实测：

| 组成 | 字符数 |
| --- | --- |
| 默认「使用说明」模板（`promptTemplates.injectGuide`） | **3726** |
| 结构头（`# FTT 记忆注入` + 2 行区块说明 + 日期行） | 约 320 |
| 结束哨兵 `记忆结束。` + 分隔空行 | 约 10 |
| **框架合计** | **约 4056** |
| 真机实测注入体 | **11955**（= 8000 正文 + ~3955 框架，**超上限 49%**） |

修法（`host/inject.js`）：

| 函数 | 作用 |
| --- | --- |
| `injectFrameOverhead({noGuide})` | 量化框架开销（含 / 不含「使用说明」） |
| `planInjectBudget(cap, frameFixed, guideLen, minBody)` | 纯函数三态：**保留说明** / **丢弃说明**（把预算让给正文）/ **不注入**（`budget-too-small`） |
| `buildAndPushInject` | 先算预算 → **向量/AI 层与本地召回共用同一正文预算** → 按 `useGuide` 组装外框；`pushStats` 增 `lastOverhead` / `lastBodyBudget` / `overBudget` |

**纪律**：绝不静默超预算；说明被丢弃时写调试日志（`发送记忆`）。
