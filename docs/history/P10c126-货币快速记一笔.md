# P10c126 · 货币「快速记一笔」（v3.50.17）

> 文档版本：v1.0 ｜ 日期：2026-10-15 ｜ 状态：生效（v3.50.17）
> 用户原话：「货币增加一个功能，除了编辑外，补充一个按钮，可以只添加一条子记录。例如收入XX元，用户只需要填写XX即可，
>   记录会被记录为'收入XX元 修正'。或者支出XX元，类似。每个货币的记录都可以触发这个简易增减记录操作，同时记录后同步修订该记录的记录金额。」
> **版本位**：用户指定 **v3.50.17** —— 新增轻量入口（无数据契约变更：`history` 结构不变）→ 守则 §3.1 的 patch 位，**无偏离登记**。
> 关联：`core/currency-quick.js`（新）· `ui/currency-quick.js`（新）· `CHANGELOG.md` v3.50.17 · 上一轮 `P10c125`（v3.50.16）

## 1. 诉求

货币记录只能「✏️ 编辑」整条（改额度 / 备注 / 流水）；记一笔小额收支要打开编辑器、手工改额度、再手写流水，太重。
要一个**只填金额**的轻量入口：填 `50` → 记成 `收入50元 修正`（或 `支出50元 修正`），**同时把该条额度同步加减**。

## 2. 改法（C11：内核纯函数 + 界面件各一个新模块）

### ① `core/currency-quick.js`（纯函数，无宿主/DOM/定时器）

| 导出 | 作用 |
| --- | --- |
| `QUICK_NOTE_SUFFIX = '修正'` | 用户指定的说明后缀 |
| `quickNoteText(dir, amount, unit)` | `收入50元 修正` / `支出50元 修正`（单位取该条 `unit`，缺省 `元`） |
| `parseQuickAmount(raw)` | 只接受**正数**（容许空格/逗号/「元」）；`0` / 负数 / 非数字 → `{ok:false, error}` |
| `applyQuickCurrencyFlow(cur, dir, amount, opts)` | 追加流水 `{date, delta:±金额, note}` + **同步额度** `amount = roundMoney(amount ± 金额)`；**不 mutate 入参** |
| `appendQuickFlow(history, flow)` | 流水并入（**不按内容去重**，见下）+ 只留最近 12 笔 |
| `quickReceiptText(...)` | 回执文案：`收入 50元 · 额度已更新为 150元` |

**与 `mergeMoneyHistory` 的差别（有意为之）**：后者给 **AI 抽取** 用（同一份正文重复抽取应去重）；
而这里是人**手动点两次同额** —— 那是**两笔真实记录**，必须都留下，故 `appendQuickFlow` 只做「追加 + 12 笔上限」。

### ② `ui/currency-quick.js`（界面件 + 动作处理）

| 导出 | 作用 |
| --- | --- |
| `curQuickButtonsHtml(id)` | 每行货币多两枚按钮：`＋`（收入）/ `－`（支出），`data-ftt-action="curQuick"` + `data-ftt-dir` |
| `curQuickFormHtml(id, open)` | 点开后**行内**展开的小表单：**只有一个金额输入框** + 确定 / 取消（不弹模态框） |
| `handleCurQuick(a, p, api)` | 动作处理：展开 / 收起 / 应用（读输入值 → 校验 → 应用 → 落库 → 回执 → 重绘） |
| `QUICK_ACTIONS` / `QUICK_INPUT_ATTR` | 动作名清单 / 输入框标记（常量，避免字符串漂移） |

### ③ 面板接线（`ui/panel.js`，**3 处**）

1. 导入新模块；
2. 行操作区：`opsInner` 里加 `(kind === 'currencies' ? curQuickButtonsHtml(id) : '')`（与「✏️ 编辑」并列，**不替代**它）；
3. 行内容：追加 `curQuickFormHtml(id, ps.curQuick)`（仅在展开时非空）；
4. 动作分支**一行**：`else if (QUICK_ACTIONS.indexOf(a) >= 0) { handleCurQuick(a, p, {...}); }`。

## 3. 交互

| 操作 | 结果 |
| --- | --- |
| 点 `＋`（收入） | 该行展开「收入 · 金额 [____] · 确定 / 取消」，并提示「会记为「收入XX 修正」并同步该条额度」 |
| 填 `50` → 确定 | 追加流水 `收入50元 修正`（`delta:+50`）→ 额度 100 → **150**；提示 `收入 50元 · 额度已更新为 150元（流水已记「收入50元 修正」）` |
| 点 `－`（支出） | 同口径，说明为 `支出XX元 修正`，额度 **减少** |
| 填 `0` / 负数 / 文字 | 不落库，提示理由（方向由按钮决定，**不由符号决定**） |
| 连点两次同额 | **两笔**都记（人工动作不去重），流水超 12 笔自动只保留最近 12 条 |
| ✏️ 编辑 | 原样保留（整条编辑仍可用） |
