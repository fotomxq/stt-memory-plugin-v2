## 2. 写盘机制（真能写才叫生效）

Tauri `fs` 插件在不同版本/ACL 下 `write_text_file` 的参数形态不同 → **逐形态试写**（`contents` 字符串 / 字节数组、`text`、`data`），
一律以「**写后回读逐字节一致**」为成功判据；读文本兼容 `string` / `{text}` / `{contents}` / 字节；`read_dir` 用于列举目录。

拿不到能力 / 写不进去：**回退浏览器层**（变量 + 内存库）+ 醒目提醒 + 把该路径标记「无效」（v3.28.1 口径，未变）。

## 3. 边界（如实）

* 能否写任意磁盘路径**取决于宿主是否放行**（本机 TauriTavern 暴露了 Tauri 原始桥，`ftt.diskProbe` 会给出实测结论）；
* 探针只写自己的 `ftt2-local-probe.json` 并删除，**不碰任何记忆数据**；
* 服务端存储（记忆文件 / 分片 / 快照）不受影响；「服务端扩展存储目录」仍是独立的高级项。
