## 2. ① 双指纹（`D8` R1=B）

| 指纹 | 函数 | 用途 | 口径 |
| --- | --- | --- | --- |
| **身份指纹** | `atomIdentityHash(cat, e)` → `i2:<hash>` | 跨端同内容去重、载入去重、**内容墓碑**、复活防护、控制台显示 | 4 基本槽（标题 / 日期 / 内容 / 地点·如有）+ 3 扩展槽（标签 / 类型 / 状态·如有）；**集合类先排序**；缺失 ≡ 空 |
| **变更指纹** | `atomContentHash` / `atomChangeHash` | **增量快照差异**、**情节签名**（分析后是否同步时钟） | V1 逐维字段表，**逐字不变** |

**接线（逐处）**：

| 位置 | 改用 |
| --- | --- |
| `core/merge.js` | `ensureAtomHashes`（条目 `h` 缓存）→ 身份；`tombEntry`（内容墓碑）→ 身份；`collectAtomHashes(mode)` 新增 `mode`：默认身份、`'change'` 取变更 |
| `core/migrate.js` | 载入同内容去重 `contentDedupeArray` → 身份 |
| `core/sweep.js` | 墓碑索引 `entryIndexBuild` 与墓碑学习 → 身份 |
| `ui/console.js` | 控制台显示 → 身份 |
| `core/snapshots.js` | 4 处 `collectAtomHashes('change')` → **变更**（快照文件语义与 V1 一致，`atomsHashes` / 聚合 hash 不变） |
| `host/preflight.js` | `atomsSignature` → **变更**（未动：原本就是变更口径） |
| `core/cross-sync.js` | **未动**：`:40`（数据聚合指纹）与 `:66/:138`（同 id 冲突判定）属「看变化」语义 → 保持变更指纹 |

**兼容与边界**：

- **未归一化的历史数据**（V1 导入 / 旧存档 / 旧版对端）：角色档案在内容副本尚未生成时，身份指纹退化为 `i2:legacy:<变更指纹>` → 不会把「同名但字段不同」的两条档案误判为同一条（测试 `hash-dual-fingerprint` C2）；
- **前缀即口径**（`D8` R19）：身份指纹带 `i2:`。跨端遇到异口径（无前缀）时，字符串不相等 → **自然跳过内容去重、只按 id 合并**；墓碑同理只认同前缀；
- **关联层为例外**（R11）：`links` 仍是「引用型」，身份指纹 = `i2:` + 现字段集；**货币**（R11）不参与身份判定（返回空串）。

## 5. ④ 重要度窗口占比（`D7`）

| 项 | 实现 |
| --- | --- |
| 公式 | `imp(i) = uses(i) ÷ Σ uses(k)`，`k ∈ [i−R, i+R]`（**含自身**，R=10 → 21 条窗口）；0 分母 → 0；存 3 位小数 |
| 重算范围 | 每次提取后各维各取**最近 N=20 条**；**第 20 条照常用真实 ±10 邻居**（分母可越过边界读窗外 uses）；**第 21 条及更旧冻结**（不写、值恒定，但仍作为分母参与） |
| 逐维独立 | 9 个维度各自成序、各自开窗；**状态记录按 `subject` 分组**（组内成序）→ 跨维、跨主体都不可比（`D7` §4.6.1） |
| 触发 | `host/preflight.js#recalibrateAfterExtract` 顶部（与时钟开关**无关**，先于任何时钟分支）→ 三个合并点（单楼 / 批量 / 手动）自动覆盖 |
| 参数 | `impRecalcEnabled`（默认开）/ `impWindowRadius`（默认 10，1-50）/ `impRecalcCount`（默认 20，1-200）；非正/非法回落默认 |
| 诊断 | `importancePreview(dim)` 只读列出「当前值 / 重算值 / 是否冻结」；`strength`（V1 兼容字段）随占比同步 |
| 展示口径 | `importancePct` 改为读**存储值**（`D7` Q5 方案 A 单轨替换）；`calcImportance` 保留为 V1 兼容纯函数，**不再用于展示/判定** |
| 阈值（C1） | 通用清扫保护 `lowUseForgetProtectImportance` **0.7 → 0.2**（均匀分布窗口均值 ≈ 1/21 ≈ 4.8%，0.2 ≈ 4 倍平均，与旧筛除力度同量级）；该控件按比例类改为**滚动条** |
| 设定落位 | 提取记忆页「重要性计算」：旧两项（初始重要性 / 每次调用增量）**下线**，代之以三个窗口参数（计数类 → 数字输入） |
