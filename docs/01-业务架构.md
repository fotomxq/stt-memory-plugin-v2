## 1. 定位与用户价值

FTT记忆组件 V2 是 **SillyTavern 原生扩展**：把长篇角色扮演里「说过、做过、发生过」的内容沉淀成结构化长期记忆，
在每次生成前按预算注入回上下文，让角色**记得住、不穿帮**。

| 痛点 | 本组件的回答 |
| --- | --- |
| 模型上下文有限，早期剧情被挤掉 | **按预算注入**：结构头 + 记忆正文 + 使用说明 + `记忆结束。`（`host/inject.js:81-106`），永不 abort、不改 chat |
| 手动记笔记负担重 | **自动提取**：生成后读新楼层 → AI 返回增量 JSON → 按口径落库（`host/extract.js`、`core/ingest.js`） |
| 记忆会互相矛盾、越积越乱 | **修复管道**（各域：状态/记忆/概念/场景/物品/角色/计划悬念）+ **遗忘衰减** |
| 角色不该知道的事却知道 | **知情关联层 + 固定约束段**：机械生成「谁知道什么」，优先级高于正文（`core/recall.js:305`） |
| 剧情时间混乱 | **剧情时钟**：只以最新情节为唯一可信来源（`core/clock*.js`），绝不用现实日期 |
| 多设备 / 换端丢数据 | **存储分层 + 快照链 + 跨端同步**（`02-数据架构` §5–§6） |

## 2. 能力全景

### 2.1 记忆维度（14 类，`core/constants.js:37-51`）

| # | 维度 | 载体键 | 说明 |

## 3. 用户旅程

| 阶段 | 发生什么 |
| --- | --- |
| 安装 | ST 从 GitHub 安装扩展 → 读 `manifest.json` → 装配（`03-技术架构` §3）；**与 V1 不可同时启用**（会重复注入） |
| 打开聊天 | 载入本角色记忆容器（本机缓冲 → 服务端文件 → 空容器）→ 挂面板 → 建索引基线 |
| 每次生成前 | 刷新记忆注入（结构头 + 正文 + 说明 + `记忆结束。`）；**永不 abort、不改 chat** |
| 每次生成后 | 提取最后一个未分析楼层 → AI 增量 JSON → 按口径落库 → 记台账 → 落盘 |
| 日常维护 | 面板查看 / 编辑 / 删除条目；按需触发修复、演化、推演、遗忘 |
| 审计 | 注入自查（本轮注入了什么、为什么别的没进去）、调试日志、交互与宿主调用时间线 |
| 换端 / 备份 | 导出 JSON / 快照链 / 跨端同步 |

## 4. 业务规则与口径（不可越界）

| # | 规则 | 依据 |
| --- | --- | --- |
| B1 | **注入永不 abort 生成、永不改写 chat**；失败一律静默 | `host/interceptor.js`、冒烟 C1/G3/H6 |
| B2 | **不用现实时间**当剧情时间；无剧情时钟时留空（不写今天） | `core/clock*.js`、`tests/unit/clock-story-only.test.js` |
| B3 | 剧情时间口径：**只取最新一条情节**；不猜、不巡检改写 | `core/recall.js#latestTrustedPlot`、`docs/P10o` |
| B4 | **V1 行为是基线**：字段名、字段顺序、算法、界面文案尽量逐字对齐 | 54 份黄金样本（oracle = 真实 V1 v1.206） |
| B5 | 有意的偏离必须**显式登记**（测试里归一 + 文档里写清） | `docs/history/P8-功能对齐总表.md` §6.5 等 |
| B6 | 删除留**双墓碑**（id + 内容哈希），跨端不复活 | `core/merge.js` |
| B7 | AI 产出的数据必须过**维度归一 + 上限夹取**；非法值丢弃而非写入 | `core/model/dims.js`、`core/ingest.js` |
| B8 | 「约束段」机械生成、零 AI、优先级高于上文任何区块 | `core/recall.js:305-369` |
| B9 | 涉密信息默认不外泄：未列出的角色一律按「不知情」处理 | 同 B8 |
| B10 | 分段总结**只归档、不注入**，唯一消失途径是手动删除 | `core/plot-segment.js` |

## 5. 数据隔离与作用域

- 记忆按**角色作用域**隔离（`getScopeKey()`）；切换聊天 / 角色即切换容器。
- 单用户本地运行；扩展**不下载、不写入、不执行远端代码**（更新检查只读远端清单，拉取由 ST 或用户完成）—— `docs/更新检查机制.md`。
- 旧版 V1 数据导入为**追加合并**，不删除源数据。
