| 项 | 内容 |

### 3.4 三项新发现的体验/规范缺口（应-8 / 应-9 / 应-10）

| 编号 | 现象 | 完善后形态 | 理由与边界 |
| --- | --- | --- | --- |
| **应-8** | **无回收站 / 恢复删除**（K7）：删除只留双墓碑，用户侧没有任何撤销路径，误删只能靠**快照链整轮回退** | 在「设定 → 数据管理」的危险区**之前**增加「🕳 最近删除（N 条）」只读列表 + 「♻ 恢复选中」（清除对应 id 墓碑）。范围限定为**本机当前作用域**、**只读列表 + 单条/批量恢复** | **不违反** `D6` §2「不做自动撤销」—— 那只约束**联动引擎**，不约束用户手动恢复；也**不改**双墓碑语义（恢复 = 清墓碑，跨端仍以墓碑为准收敛）。**需用户裁决**（§6 Q2） |

| **应-10** | **ARIA tabs 模式不完整**（K9）：有 `role="tab"` + `aria-selected`，但无 `tabindex` 管理、无左右方向键 | 补齐 WAI-ARIA tabs 的最小可用集：选中页签 `tabindex="0"`、其余 `tabindex="-1"`；`←/→` 切换并把焦点移入新页签；标签条 `role="tablist"` 上加 `aria-label` | 属 `D9` §10 **U8（可达性）**的延伸；**纯新增属性与键盘处理**，不改类名与 DOM 结构（与 `D9` §4「公共件改动需全站回归」一致，按公共件回归） |
