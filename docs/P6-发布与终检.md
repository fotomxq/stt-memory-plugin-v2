## 1. 发布物形态

V2 是**标准 SillyTavern 第三方扩展**：**源码即发布物**（无构建步骤、无依赖、无 `node_modules`）。
安装方式（三选一）：

1. ST 界面 → 扩展 → 「安装扩展」→ 填仓库地址 `https://github.com/fotomxq/stt-memory-plugin-v2`（分支 `main`）；
2. 手动：把仓库目录放到 `SillyTavern/data/<user>/extensions/stt-memory-plugin-v2/`；
3. 指定 tag 安装（ST 支持按分支/标签安装）：`v2.0.0`。

安装后 ST 读取 `manifest.json`（`version 2.0.0`、`generate_interceptor`、`hooks`、`i18n`、`auto_update`），
在 `APP_READY` 装配；无需重启任何构建服务。

## 2. 词条（i18n）

| 文件 | 用途 |
| --- | --- |
| `i18n/zh-cn.json` / `i18n/en.json` | 供 ST 自动扫描（约定路径 `i18n/<locale>.json`） |
| `i18n/zh-cn.js` / `i18n/en.js` | ESM 镜像（**由 JSON 生成**，运行时直接 import，无需 fetch） |

- **键口径**：一律以界面上的**中文字面量**为键（`zh-cn` 为身份映射，`en` 为译文），共 47 条，覆盖设定面板 / 数据台 / 命令 / 动作提示；
- 注册：`adapters/i18n.js#registerLocaleData()` 在 `init()` 中调 `ctx.addLocaleData(locale, dict)`（兼容两参/单参签名，失败只记原因）；
- 取词：`t(key, vars)`（缺失回退键本身，支持 `{n}` 占位）；`FTT.t()` / `FTT.i18n()` 调试可用；
- 门禁：`scripts/check-i18n.js` 强制「两份 JSON 键集一致 + JS 镜像与 JSON 逐值一致」——镜像不可能悄悄漂移。

> 说明（未完成的诚实边界）：模板 `settings.html` 的文案目前是**中文直书**，ST 的 `{{t}}` 模板级替换尚未接入；
> 词条已就绪（en 译文可用），但英文界面下模板仍显示中文。该项登记在 §5。

## 4. 发布物自足性验证（归档级）

```bash
git archive --format=tar v2.0.0 | (mkdir -p /tmp/ftt-v2-release && tar -x -C /tmp/ftt-v2-release)
cd /tmp/ftt-v2-release && npm run gate      # 无 node_modules、无网络
```

在**归档导出的干净目录**里跑完整门禁，证明「仓库里有的就是能跑的全部」——
没有未提交文件、没有本地生成物、没有隐式依赖。证据见 `CHANGELOG.md` 对应版本条目与本文件 §3。
