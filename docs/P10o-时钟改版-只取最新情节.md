# P10o · 剧情时钟改版：只取最新情节（v2.51.0）

> 文档版本：v1.0 ｜ 日期：2026-09-26 ｜ 状态：生效（v2.51.0）
> 触发（用户要求）：「时钟设计存在大量缺陷，改版**只从情节最新的一条获取**，其他所有原子数据皆不可信；
> 其次**情节总结不涵盖在内**。注意改版后，总览提示、设定需根据时钟新设计进行调节，**去掉废弃设定或提示内容**。」
> 后续决定：①「第 N 天」是原子数据兼容任意时间格式**预留的天数计数器** → 保留字段，但不与时钟联动、不参与注入；
> ②「时间巡检修复」没有意义 → **功能移除**。所有修改**仅针对 V2**（V1 仓库只读、不再改动）。

---

## 1. 新设计（唯一可信来源）

| 项 | 改版前（V1 口径） | 改版后（v2.51.0） |
| --- | --- | --- |
| 日期/时间/地点来源 | 正文头结构 → 正则预设/自定义正则 → 标记式 → 相对日期推进 → 最新情节 → 原子数据最新日期 → 沿用旧值 | **最新一条「情节」**的 `date`/`time`/`location` |
| 正文解析 | 直接落盘时钟（`▷ 日期` / `▶ 第 N 天 → 日期` 等） | **完全不参与**（正则/正文头/标记式/相对日期/第N天换算全部退出时钟） |
| 其他数据类别 | 记忆/角色/物品/货币/传言/计划/悬念/场景/概念/平行 可作候选或降级来源 | **既不取值、也不降级、也不巡检** |
| 情节总结 | 参与 | **不参与**：`mergedSummary`（含半自动聚合条）、`summarizedBy`/`hidden`（已总结隐藏的原情节）、`plotSegments`（分段总结）全部排除 |
| 最新情节缺日期 | 回退到其它来源 | 只在**情节内**回退到次新**带日期**的情节；完全没有 → **不改动时钟**（不清空、不引他源） |
| 手工改写 | 最高优先（锁定） | 不变（`✏️ 手工改写日期/时间/地点`；`cfg.clockManualLock` 默认锁定） |

实现：`core/recall.js#latestTrustedPlot()`（新）、`core/clock-extract.js#resolveStoryClock()`（重写）、
`storyClockReference()`（同样只取情节）。

## 2. 「第 N 天」= 保留字段（保留但**不联动**）

- 定位：**原子数据兼容任意时间格式预留的天数计数器**（用户说明）。
- 落地：`recordReservedStoryDay()` 在每次时钟同步时，把该情节正文头里的 `▶第 N 天` 记到**该情节的 `storyDay` 字段**
  （示例：`▶第 500 天 …` → `atoms[].storyDay = 500`）。
- **不做**：不换算日期（`clockStoryDayEpoch` 设定连同换算一并删除）、不写 `state.state.storyDay`、不参与注入、
  不在总览作为时钟相关提示展示。
- 门禁：`tests/unit/storyday-no-inject.test.js`（R/N/S 组）。

## 3. 「时间巡检修复」功能移除

- 删除：总览「🩺 时间巡检」状态行与按钮、`clockPatrol` / `clockPatrolForce` 动作、`runClockPatrolRepair`、
  `clockPatrolAutoOnce` / `clockPatrolState`、载入后自动巡检调度、`clockPatrolMajority`（原子年份多数派）、
  「年份漂移/异常阈值」判定、设定页「时间巡检」整节、FTT 入口 `clockPatrol*` / `clockMajority` / `clockDegradeLabel`。
- 保留：`clockPatrolScan()`（只扫情节、只报**格式非法**）作为「🩺 AI 结合正文修复日期时间」的异常打包依据；
  锚点 = 手工改写 ＞ 当前时钟（都来自可信情节）；无锚点 → 不执行；写回前仍建全量快照。
- 年份异常阈值改为**内部常量** `CLOCK_JUMP_YEARS_DEFAULT = 50`（V1 默认值），仅用于写回安全闸门。

## 4. 删除的设定与提示（不留废弃内容）

| 已删除设定 | 原因 |
| --- | --- |
| `clockRegexPreset` / `clockDateRegex` / `clockTimeRegex` / `clockLocationRegex` / `clockRelative` | 正文直取退出时钟 |
| `clockStoryDayEpoch` | 第 N 天不再换算日期（改为保留字段） |
| `clockForceDegrade` | 降级方案取消（只有情节一个来源） |
| `clockAnomalyJumpYears` | 年份异常判定取消（阈值改为内部常量） |
| `clockAutoPatrol` / `clockPatrolAutoFix` | 巡检修复功能移除 |

同时删除的提示：降级说明、日期跳变提示、「剧情第 N 天（校准用）」行、「🤖 AI 捕捉正文 → 生成正则」按钮与
`clockRegexGen` 提示词模板、调试页「时间巡检（锚点与修复）」「AI 捕捉正则」两节。
设定控件：基础页 21 → 11 项、全站 183 → 173 项。
