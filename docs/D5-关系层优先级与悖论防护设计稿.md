## 0. 一页摘要与本轮裁决

**一句话**：**情节（`atoms`）是唯一的事实锚，恒定不可被衍生改写；其他 13 个大类都是它的衍生** ——
优先级不是「谁的字段更权威」，而是「**离已发生的事实有多近**」。

| # | 本轮裁决（用户） | 落实位置 |
| --- | --- | --- |
| 1 | 情节永远是已发生的事实 → **恒定**；平行 / 传言预兆未来 → **次要**；其他以此类推 | §2 锚定模型 + §2.3 维度权威序（按两轴推导） |
| 2 | **因果环随情节发生改变和演进**，引发记忆 / 状态 / 平行 / 传言变化演进 | §4 因果演进（检测保留，**不阻断**） |
| 3 | **最终归一还是到情节**，其他都是扩展出去的衍生 | §2.1 锚定三原则（A1–A3） |
| 4 | **人工可提升到情节**（平行已有此能力），后续给其他维度追加**层层递进的提升** | `D6` 提升阶梯（本文 §5.3 保留单向规则） |
| 5 | **跨端必须一致；出现差异取时间最新的为基准** | §3.3 跨端裁决（本文原「内容哈希字典序」降级为**仅完全同时刻**的兜底） |
| 6 | 其他按建议处置（对称边物理归一、环只报告、平局保留双条） | §3.1 / §4 / §3.1 兜底行 |

## 1. 紊乱的六种形态（先定义问题）

| # | 形态 | 例子 | 今天会怎样 |
| --- | --- | --- | --- |
| ① | **对称双写** | A、B 各存一条 `co-occur` | 去重键含方向 → 永不收敛为一条 |
| ② | **反向断言** | `A before B` 与 `B before A` 同时 active | 两条都"有效"，无人判定 |
| ③ | **有向环** | `A caused B caused C caused A` | 静默接受（**本轮裁决：不阻断，见 §4**） |
| ④ | **传播震荡** | D4 传播中 A 变触发 B、B 变又触发 A | 靠上限止血，语义未定义 |
| ⑤ | **同源冲突** | 同 subject+kind 多条相互矛盾 | 只有 `D2` §4.3 草案 |
| ⑥ | **跨端平局** | 同 id 同 `updatedAt`、内容不同 | **互相取对方 → 振荡**（§3.3 隐患） |

**根因**：缺少**全序** —— 一旦「无法比较」，实现就会回落到「本地/远端优先、先到先得、数组下标、随机」，而**这些都不是确定性函数**。

## 2. 锚定模型：情节是事实锚，其余都是衍生

### 2.1 三条锚定原则

| # | 原则 | 含义 |
| --- | --- | --- |
| **A1** | **单一锚** | `atoms` 是唯一的事实本体；其余维度是它的**投影**（认知 / 状态 / 归属）、**意图**（计划 / 悬念）或**推测**（推演 / 传言） |
| **A2** | **不可逆写** | 衍生层**永远不得改写 `atoms` 正文**；只能 ① 追加新情节 ② 标记（受影响 / 作废 / 已证实）③ **提升**（人工，`D6`） |
| **A3** | **终审锚** | 任何冲突的最终裁决回归 `atoms`；无法回归时按**最保守口径**（保留双方 + 标记 `conflicted`），**永不静默丢一条** |

> A2 是防「A 变 B、B 变 A」的**根本**：只要衍生层不能回写事实层，环就只能是**诊断对象**，不会是**污染源**。

### 2.2 两条轴 → 推导维度序

| 轴 | 取值 |
| --- | --- |
| **时间定位** | 已发生 / 当下 / 未发生 |
| **事实性** | 事实本体 / 恒定身份 / 当下快照 / 对事实的认知 / 元信息（谁知道） / 未发生的意图 / 未发生的推演 / 未证实的信息 |

| 维度 | 时间定位 | 事实性 | 离事实的距离 |
| --- | --- | --- | --- |
| `atoms` 情节 | 已发生 | **事实本体** | **0（锚）** |
| `snapshots` 角色档案 | 跨时间恒定 | 恒定身份 | 1（恒定事实） |
| `currentStates` 状态记录 | 当下 | 当下快照 | 2（当下事实，易变） |
| `memories` 长期记忆 | 已发生 | 对事实的认知 | 3（二阶，可失真） |
| `links` 关联层 | 跨时间 | 元信息（谁知道） | 4（三阶） |
| `plans` / `suspense` 计划悬念 | 未发生 | 意图 / 未解 | 5（指向未来） |
| `parallels` 平行事件 | 未发生 | **推演**（明确标注未发生） | 6 |
| `rumors` 传言 | 任意 | **未证实**（可失真、可传导） | 7（最低） |
| `plotSegments` 分段总结 | —— | 归档（**不注入**） | 不参与 |
| `currencies` 货币 | 当下 | 独立账本 | 不参与 |

### 2.3 维度权威序（推导结果）

```text
T0 atoms（事实锚，恒定）
T1 snapshots（恒定身份）
T2 currentStates（当下事实）
T3 memories（已发生·认知）
T4 links（元信息：谁知道）
T5 plans / suspense（未发生·意图与未解）
T6 parallels（未发生·推演）
T7 rumors（未证实·可失真）
不参与：plotSegments（只归档） / currencies（独立账本）
```

**推导规则**（可复算、可调整）：先比**时间定位**（已发生 > 当下 > 未发生），同定位再比**事实性**（事实 > 认知 > 元信息 > 推演 > 未证实）。
**与用户口径的一致性**：情节恒定居顶；平行（T6）与传言（T7）作为「预兆未来」而居末 —— 与「可以做次要」完全一致。

### 2.4 与「认知可靠度」的关系（保留）

`REL_LINK_HOW_RANK`（`core/model/rel.js:200`）与 `HOW_ORDER`（`ui/rel-table.js:48`）是**同一维度内**的可靠度序，
用于排序与展示；**并入 L2 的「维度内比较」**，不作为跨维度的权威依据。

## 3. 优先级链（L0 → L4）

判定**永远从 L0 开始**，能定则止；只有上一层完全打平时才下探。

| 层 | 名称 | 规则 |
| --- | --- | --- |
| **L0** | **存在性** | **删除恒胜**：墓碑（id 优先，内容哈希次之）覆盖一切（`core/merge.js:98/110/123`） |
| **L1** | **强度 / 状态** | `hard > soft`；`confirmed/active > pending > expired > retracted` |
| **L2** | **来源 × 维度权威序** | `source`：`manual > ai(带 evidence) > mech > inferred`（**ai 无 evidence 拒收**）；再按 §2.3 的 T0–T7。**人工永远压过 AI**，即使维度更低 |
| **L3** | **事实时间** | 剧情时间**新 > 旧**（仅同级使用）。**禁止**用时间推翻因果方向 |
| **L4** | **跨端 / 平局裁决** | 见 §3.3：**取时间最新**；**完全同时刻**时用**内容哈希字典序**兜底 |
| 兜底 | —— | **保留双条 + 标 `conflicted` + 最保守口径**（永不静默丢） |

### 3.1 三条硬约定

1. **A2 优先于一切比较**：任何比较都不得产出「衍生改写事实锚」的结果；
2. **兜底不丢数据**：同层同时间仍冲突 → 双条 + finding（用户裁决 ⑥ 采纳）；
3. **无随机**：不得使用 `Math.random`；必须随机的场景沿用种子哈希（`core/rumor-evolve.js:86`），保证两端一致。

### 3.2 含义速览：同一冲突怎么判

| 冲突 | 裁决 |
| --- | --- |
| 人工加的关联 vs AI 产出的关联 | L2 来源：人工胜 |
| 传言说「A 死了」vs 情节写「A 活着」 | L2 维度：情节（T0）胜；传言被标记（`D4` 的 `mark` / `dissolve`） |
| 平行推演「B 会来」vs 情节「B 没来」 | 情节胜 → 平行条按 `dissolve` 标记作废（不删除） |
| 两条 AI 约束互相矛盾 | L1 强度 → L2 来源 → L3 时间 → 兜底双条 + finding |
| 两端同 id 不同内容 | §3.3：取时间最新；完全同时刻 → 字典序兜底（两端同结果） |

### 3.3 跨端裁决（用户口径：取时间最新）

**比较链**：

```text
① 条目 updatedAt 较大者胜
② 相等 → 存档级 updatedAt（store mtime）较大者胜
③ 仍相等 → 内容哈希字典序（确定性键，全端统一取小者或大者）
④ 仍无法判定（哈希相同）→ 内容相同，无需裁决
```

**两条必须做的事**：

| # | 事项 | 为什么 |
| --- | --- | --- |
| **C1** | 现存隐患修正：`core/cross-sync.js:141-146` 的平局分支是 `winRemote = rw > lw \|\| (rw === lw && remTs > baseTs)` —— **「谁在远端」不是内容的函数**。两端都在 base 之后改动且两级时间相同时，**两端互相取对方 → 振荡不收敛** | 必须改为上面的 ①→③ |
| **C2** | `updatedAt` **必须非 0**：`links` 归一默认 `0`（`core/model/rel.js:38`），而「取时间最新」依赖时间存在；两条 `updatedAt = 0` 的记录无法用时间裁决 | 归一环节统一写入时间戳（或统一用内容哈希兜底），否则 C1 的 ③ 会频繁触发 |

> **为什么保留 ③**：这不是偏好问题 —— 「取最新」在**完全同时刻**时**不可判定**；若此时仍按「本地/远端」决定，
> 两端必然得出相反结论。③ 是让「取最新」真正可收敛的数学前提（Q6 的答案由此落定）。

## 4. 因果环：不是要切断，而是要随情节演进

**用户口径**：「因果环会随着情节发生改变和演进，从而引发记忆、状态、平行、传言等变化演进。」

因此本稿对 §D5 v0.1 的定位作**修正**：

| 项 | v0.1 措辞 | v0.2 定位 |
| --- | --- | --- |
| 因果环检测 | 「检测并报告，不自动断环」 | **保留检测**，但定位于**诊断**：发现「停滞环 / 悖论环」，而不是障碍 |
| 处理策略 | 报告 + 人工干预 | **随事实收敛**：环上节点被新情节「实现」时，出边自然被事实收窄、环自行解开；`D4` 传播沿 M1 单向推进 |
| 需要人工的情形 | —— | **停滞环**（长时间未被任何新情节推进）→ 提示用户，或由人工**提升**其中一条（`D6`）来打破 |

**因果演进示意**：

```text
情节 a1 发生 ──► 因果链下游被收窄（caused 出边指向的分支减少）
             ├─► 记忆：知情者更新（memories / links）
             ├─► 状态：当下状态重算（currentStates）
             ├─► 平行：与之互斥的推演标记作废（parallels dissolve）
             └─► 传言：说法被证实/证伪，发酵度与阶段变化（rumors）

环 A→B→C→A：当 C 被新情节「实现」，A 的推演前提消失 → 环解开（不是被砍断）
```

**与 M1 的关系**：正因为 A2「衍生不得回写事实」，环**不会**变成「A 改 B、B 改 A」的污染回路；它只能是**待演进的悬念结构**。

## 5. 传播层的优先级与单调性（接 `D4`）

### 5.1 同一跳内多动作命中同一条目

```text
dissolve（作废） > narrow（收窄） > recompute（重算） > advance（推进） > mark（标记） > annex（留痕）
```

### 5.2 单调性三律

| # | 律 | 含义 |
| --- | --- | --- |
| **M1** | **权威单调** | 只从高权威指向低权威（T0 → T7）；**低权威不得反向改写高权威**（传言不得改情节） |
| **M2** | **时间单调** | 只沿剧情时间向前；不得改写历史事实，只能追加或标记 |
| **M3** | **单向遍历** | 同一条边一轮只走一次；**禁止 A→B→A 回写源** |

**收敛保证**：A2 + M1 + M2 + M3，配合 `D4` 的有界（I3）、幂等（I1）、确定性（I2）→ **一轮传播必然终止，且两端同结果**。

### 5.3 唯一的「低权威 → 高权威」通道：提升（Promotion）

低权威**永远不能改写**高权威，但可以**晋升**（产生新事实，而非修改旧事实）：

| 既有 | 现状 |
| --- | --- |
| 平行转正 | `core/parallel.js:498-548`（人工触发，写情节 + 移除平行条 + 墓碑） |

**用户要求把这条能力通用化、层层递进** → 详见 `D6-维度提升阶梯设计稿.md`（每一步都需人工确认，AI 不得自动晋升）。

## 6. 速查表

**表 1 · 裁决链**：L0 删除恒胜 → L1 强度/状态 → L2 来源 × 维度序（T0–T7）→ L3 剧情时间 → L4 时间最新（跨端）+ 字典序兜底 → 双条 + finding。

**表 2 · 维度序（Tier）**：`atoms(锚) > snapshots > currentStates > memories > links > plans/suspense > parallels > rumors`；`plotSegments` / `currencies` 不参与。

**表 3 · 动作强度序**：`dissolve > narrow > recompute > advance > mark > annex`。

**表 4 · 边类型属性**：

| 边 | 方向性 | 可成环 | 反向重复处理 |
| --- | --- | --- | --- |
| `knows` / `knows-not` | 有向 | 否 | 不同角色 → 合法；同角色反向 → L1 状态裁决 |
| `caused` | 有向 | **是（诊断项）** | 反向 = 反向断言 → L0–L4 裁决 |
| `before` | 有向（反对称） | **是** | 反向 = 同一关系 → 归一；与 `after` 同向 → 冲突 |
| `co-occur` / `mirrors` | 对称 | 否 | **物理归一**为 canonical 一条 |
| `owns` / `located-at` / `member-of` | 有向 | `member-of` 可 | 反向 = 不同关系；语义互斥 → 冲突 |
| `derived-from` | 有向 | **是（诊断项）** | 反向 = 互为来源 → 冲突（来源不得互为来源） |

**表 5 · 跨端裁决链**：条目时间 → 存档时间 → 内容哈希字典序。
