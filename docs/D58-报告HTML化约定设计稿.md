## 0. 一页摘要

把"报告"这一产出从**纯 Markdown** 改为**双轨**：**MD 是契约与门禁载体，HTML 是阅读与效果预览版**，两者同名同前缀、**同轮一起更新**。

| 轨 | 载体 | 职责 | 谁在读 |
| --- | --- | --- | --- |
| **契约轨** | `docs/*.md` | 实施规格（`业-/应-/数-/技-<n>`）· `U` 编号 · 引用检查 · **C12 双向一致** | **门禁脚本**与人 |
| **阅读轨** | `docs/reports/*.html` | 排版友好、可折叠、**含界面效果模拟（mockup）**、可离线打开 | **人**（评审 / 决策） |

**为什么不能只留 HTML**：`scripts/check-ledger-sync.js`（**C12**）与 `check-docs-facts.js`（C5/C6/C8）**只解析 MD**；`D22` 的条目、`D17` 的 `U` 编号都寄生在 MD 上。若把设计稿改成 HTML，**台账一致性、引用存在性、目录树等式会全部失守**。因此本约定**不是替换**，而是**增加**一条阅读轨。

| 要素 | 结论 |
| --- | --- |
| **默认格式** | 报告类产出**默认 HTML**，放 `docs/reports/` |
| **命名** | 与来源 MD **同名同前缀**（`<同名前缀>.html`）；首页注明**来源 MD + 版本** |
| **自包含** | 无外链、无 CDN、无第三方依赖；样式内联（与"源码即发布物、零运行时依赖"一致） |
| **效果模拟** | 界面 / 交互类设计稿的报告**应含静态 mockup**（布局 / 层级 / 徽标 / 窄屏折叠），只示意、不承诺像素级 |
| **迁移** | **MD 更新即同轮更新/迁移**其 HTML；存量**逐份**按"最近一次更新轮"补，**不一次性重写全站** |
| **首个实例** | `docs/reports/D57-城镇发展设计稿.html`（来源 `docs/D57`，含桌面 / 地图子页 / 窄屏三态） |

## 1. 目标 / 非目标

### 1.1 目标

1. 明确**双轨分工**：MD 管契约与门禁、HTML 管阅读与效果（§3.1）；
2. 给出**命名、目录、自包含**的硬规则（§3.2）；
3. 给出**效果模拟**的最低要求（§3.3）；
4. 给出**更新与迁移**的节奏与判据（§3.4）；
5. 给出**校验口径**：如何机械判定"MD 改了但 HTML 没跟上"（§3.5）；
6. 按 `开发守则.md` §2.8 立项（§8）。

### 1.2 非目标（明确不做）

- N1 **不改任何代码 / 不动版本号 / 不打 tag**（设计轮次）；
- N2 **不用 HTML 替换 MD** —— 见 §0 的"为什么不能只留 HTML"；
- N3 **不引入前端框架 / 构建链**（无 npm 依赖、无打包；纯静态文件）；
- N4 **不做交互式报告**（不做运行时数据加载、不引 CDN 脚本）；
- N5 **不一次性迁移全部存量 MD**（触及即合规，逐份补）；
- N6 **不改 `docs/history/**` 与 `CHANGELOG.md`**（快照与机读，非报告）。

## 3. 方案

### 3.1 双轨分工（不可互相替代）

| 判据 | MD（契约轨） | HTML（阅读轨） |
| --- | --- | --- |
| 门禁解析 | ✅ 唯一可解析 | ❌ 门禁不读 |
| 实施规格 / `U` 编号 | ✅ 必须在此 | ❌ 不重复定义 |
| 引用与目录树 | ✅ 受 C5/C6/C8 约束 | ❌ 不受约束（但**不得**出现不存在的反引号路径） |
| 排版与效果 | 有限 | ✅ **主战场**：分层、折叠、mockup、打印友好 |
| 版本 | ✅ 头部 `> 文档版本` | ✅ 首页**必须**注明来源 MD 与版本 |

> **一句话**：**改契约改 MD，给人看改 HTML；两者同一轮一起动。**

### 3.2 命名 · 目录 · 自包含（硬规则）

| 项 | 规则 |
| --- | --- |
| 目录 | **`docs/reports/`**（唯一报告目录；不散落在 `docs/` 顶层） |
| 命名 | `docs/reports/<来源 MD 同名>.html` —— 例：`docs/D57-城镇发展设计稿.md` → `docs/reports/D57-城镇发展设计稿.html` |
| 首页元信息 | **必须**含：来源 MD 路径、MD 版本、本 HTML 版本、日期、状态 |
| 自包含 | `<style>` 内联；**禁止** `<script src>` / `<link rel="stylesheet" href>` / 任何 CDN / 任何外链图片 |
| 可达性 | 语义标签（`header`/`section`/`h2`）、`lang="zh-CN"`、正文对比度达标；**无 JS 也能读全** |
| 打印 | 纯 CSS 即可打印（`@media print` 可选，不强制） |

### 3.3 效果模拟（界面类报告的最低要求）

| 要求 | 说明 |
| --- | --- |
| **必须示意** | 该设计涉及的**页面落点**（哪个分页 / 子标签 / 侧栏） |
| **必须示意** | **信息层级**：首行标题 + 徽标 / 中段关键信息 / 尾段操作（沿用 `D55` 三段式） |
| **必须示意** | **状态差异**：至少两种（如"有数据 / 空态"，或"正常 / 异常徽标"） |
| **建议示意** | **窄屏折叠**形态；边界情况（超上限、缺失字段） |
| **明确边界** | mockup 为**静态示意**：不承诺像素级一致、不含真实交互、数据为**虚构样例**并标注"示意数据" |

### 3.4 更新与迁移节奏

| 场景 | 动作 |
| --- | --- |
| **新报告类设计稿** | 同轮产出 MD（契约）+ HTML（阅读） |
| **既有 MD 被更新** | **同一轮**更新其 HTML；HTML 首页版本号随 MD 递增 |
| **既有 MD 无 HTML** | **不追溯批量**：在该 MD **下一次更新**时补出 HTML（触及即合规） |
| **MD 删除 / 更名** | 同步删除 / 更名 HTML，并在 `docs/README.md` 的 `reports/` 行更新说明 |

> **例外**：`docs/history/**`、`CHANGELOG.md`、`docs/D17`·`D22` 两个台账**不要求** HTML（它们是快照 / 机读 / 逐条记录）。

### 3.5 校验口径（可机检）

| 编号 | 判据 | 强度 |
| --- | --- | --- |
| **R-1** | `docs/reports/*.html` 的**文件名**必须能对应到一份**存在的** `docs/*.md`（同名同前缀） | 可机检（脚本） |
| **R-2** | 报告 HTML **首页**必须出现其来源 MD 的文件名（`<名>.md`） | 可机检（文本包含） |
| **R-3** | 报告 HTML **不得**含**真正的外链引用** —— 判据按**链接属性**：`href="http…"` / `src="http…"` / `url(http…`（**正文提到 `http://` 为例外**，不算外链） | 可机检（属性级扫描） |
| **R-4** | 报告 HTML **不得**含 `<script src=` / `<link rel="stylesheet"` | 可机检 |
| **R-5** | **MD 比 HTML 新**（`mtime`）时给出**提示**（不阻断，因"同轮"允许任意先后） | 可机检（弱判据） |

> **落地建议**：R-1～R-4 做成 scripts/check-reports.js 并入 `npm run gate`（**阻断**）；R-5 只提示。
>
> **建规自检发现（v1.0 当轮）**：按上表对首批 2 份报告做人工核对时，抓到两类问题 ——
> ① **命名**：HTML 初版文件名少了「设计稿」三字（`D58-报告HTML化约定`），与来源 MD `D58-报告HTML化约定设计稿.md` **不同名**（违反 R-3 的命名规则）→ 已更名对齐；
> ② **R-3 误判**：原表述"不得含 `http://`/`https://`"用**裸字符串**扫描，会把**正文中解释规则时提到的**协议字样判成外链 → 判据已收紧为**按链接属性**（`href=`/`src=`/`url(`）判定。
> 结论：**R-1 与 R-3 都必须按"结构"判、不能按"字符串出现"判** —— 这正是 `技-64` 实现时的硬要求。

| **P3（存量迁移）** | 按"最近一次更新轮"逐份补 HTML（报告型设计稿优先） | 量大，必须逐份、可按需 | 每补一份即在其 MD 头部加 HTML 指针 |

## 5. 风险与对策

| # | 风险 | 对策 |
| --- | --- | --- |
| R1 | **有人只改 HTML、不改 MD** → 契约与阅读不一致，且门禁看不见 | §3.1：契约只认 MD；评审以 MD 为准；HTML 首页标注"阅读版，契约见 MD" |
| R2 | **HTML 成为第二份真相** | HTML **不重复定义**实施规格与 `U` 编号（只摘要 + 指向 MD） |
| R3 | 报告体积膨胀（内联样式 + mockup） | 单份报告**单文件**，可用共享片段粘贴但不引外链；必要时内联样式**压缩**为一份模板 |
| R4 | 报告与代码不一致（mockup 画了未实现的东西） | mockup 明确标"**示意**"；报告状态列写"草稿/生效"，不标"已实现"除非实现落地 |
| R5 | 存量迁移变成"大扫除"拖慢主线 | N5：**不一次性重写**，触及即合规 |
| R6 | 自包含导致无法用统一换肤 | 短期可接受；若将来要换肤，改为**构建期内联**（仍保持单文件产物，不引运行时依赖） |
