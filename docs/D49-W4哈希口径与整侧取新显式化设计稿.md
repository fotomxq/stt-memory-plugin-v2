## 1. 目标 / 非目标

### 1.1 目标

1. **① 指纹变化不得判为删除**：`id 仍在` 与 `同内容仍在` 两条护栏在 `core/sweep.js#tombstoneSweep` 显式成文，并有单测锁（内容改写 / 跨口径指纹刷新都不产生墓碑）；
2. **② `validity` 只升不降 + 补空**：`active` < `uncertain` < `inactive`，跨端合并时取更保守一侧；胜出侧缺该字段则补空；
3. **③ 跨口径指纹登记**：`hashGuardReadout()` 暴露「已有 `it.h` 但与当前口径不一致」的刷新计数（只读）；
4. **Q3 删死键**：删除 `calcImportance` 函数与 `importanceBase` / `importancePerUse` 两个配置键，并同步设置页与 V1 黄金键表；
5. **`数-4` 方案 A**：整侧取新**显式化**（文档写清后果 + 合并留痕 + 体检如实提示），不改合并口径。

### 1.2 非目标（明确不做）

* **N1 不改跨端合并口径**：非原子容器**仍是整侧取新**（方案 A = 显式化，不是改行为）；
* **N2 不做体积/副本簇**（`数-5`～`数-8`）—— 高风险，须先补测试（`数-6` 的前置就是「先补测试」）；
* **N3 不递增 `DATA_VERSION`**：`数-3` 属 `D15` 类别②（需登记），无数据契约形态变更；`数-4` 只加留痕字段（`state.meta` 下的可缺省读数）；
* **N4 不改提示词逐字文本**。

## 3. 方案

### 3.1 `数-3` ①：两条护栏显式化（`core/sweep.js`）

`tombstoneSweep` 的判定顺序固定为：**id 仍在 → 不是删除**；**同内容（任一哈希口径）仍在 → 不是删除**；两者都不成立才 `tombSet`。
「指纹变化」只会让第二条失效，**不能**成为删除的唯一依据（本版把这段约束写进代码注释，并用单测 A2 锁死「改写同 id 不产生墓碑 / id 消失才 +1」）。

### 3.2 `数-3` ②：`validity` 只升不降 + 补空（`core/floor-cover.js`）

```text
VALIDITY_RANK = { active: 0, uncertain: 1, inactive: 2 }
other 有值 且 rank(other) > rank(target 或 'active') → target.validity = other.validity（记 'validity'）
```
效果：**旧副本的 `active` 不会把已失效条目降级复活**；胜出侧缺字段时补空；两侧同值时不制造假变更。

### 3.3 `数-3` ③：跨口径指纹读数（`core/merge.js`）

`ensureAtomHashes` 在「已有 `it.h` 且 ≠ 当前口径」时：刷新（幂等）+ `hashGuardForeign += 1`；
`hashGuardReadout()` 返回 `{foreign, lastAt}`（只读）。**绝不因此判删除**（删除判定只见 3.1）。

### 3.4 `数-3` Q3：删死键

删除 `core/recall.js#calcImportance`、`core/config.js` 的 `importanceBase` / `importancePerUse`、`ui/settings-pages.js` 的夹取分支；
`tests/unit/importance-placement.test.js` 的断言改为「确实删干净」；`tests/unit/config-clock-golden.test.js` 的 `REMOVED_V1_KEYS` 追加两键（与 10 个时钟键同款登记）。

### 3.5 `数-4` 方案 A：整侧取新显式化

1. `mergeDataObjects` 在非原子分支记录 `stat.wholeSide = {side, dims, baseTs, remTs}`（无则 `null`）；
2. `adapters/sync.js#applyRemoteMergeToState` 把结果落成 `state.meta.crossMerge = {at, wholeSide, conflict}`（可缺省、只读）；
3. `core/data-health.js` 新增 finding **`cross-wholesale`（info）**：列出容器名 + 「对端改动会被整体丢弃」+ 设计取舍出处；
4. `docs/02` §1.2 的容器行补上**后果**与可观测出口。
