## 2. 与 V1 的差异（逐条明示）

1. **`buildRepairPrompt` 为同步纯函数**：V1 声明为 `async`（函数体内无 `await`），V2 改为同步（返回值一致）；黄金样本比对时对 V1 的 Promise 做 `await`。
2. **AI 通道**：V1 自建 OpenAI 兼容请求；V2 走共用注入钩子（ST `generateRaw`，见 B8-3/B8-4 同一套接线）。
3. **任务管线 UI 未移植**：V1 的 `pipeStart/pipeUpdate`/`abortTick` 与「中断」语义在 V2 不存在；AI 段以「长任务在途拒绝」处理。
4. **`bumpRepairOp` 接线点**：V1 在摘要/提取管线与事件层各调一次；V2 在 `host/extract.js` 的单楼与分段成功落库后各调一次（同口径、更集中）。
5. **候选筛选的随机步长**：与 V1 完全一致（`Math.random` 决定步长）——因此黄金样本的场景刻意保证**中间带为空**，使该分支不参与、整条链路确定可比。
