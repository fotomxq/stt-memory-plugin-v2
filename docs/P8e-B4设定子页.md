## 1. 对齐方式（为什么键与文案能保证一致）

不手写页面，而是**从 V1 源码自动提取控件表**：

```text
V1 src/modules/13-UI-设置与存储开关.js
  ├─ subTabs = [['base','基础'], …, ['about','关于']]            → 14 组子页（顺序与标签逐字）
  └─ 各页分支 activeSettingsSub === 'x' 内的控件调用
        f('key','标签','type')            → 文本 / 数字 / 下拉
        swT('key','标签',note) / swForce(...) → 开关（含“由及时分析强制开启”语义位）
        stSwitch('key','标签',hint,badge)  → 存储类开关（写回 cfg.storage.*）
提取结果：**105 个控件**，逐页数量 —— 基础 12 / 投喂范围 12 / API 0 / 分析记忆 3 / 内容弱化 0 / 提取记忆 18 /
遗忘 25 / 传言 12 / 平行 5 / 提示词 5 / 存储 13 / 调试 0 / 数据管理 0 / 关于 0
```

生成的 `SETTINGS_TABS` / `SETTINGS_CONTROLS` 内嵌在 `ui/settings-pages.js`，**键与标签不再由人手维护**；
测试 P3 断言「105 个键必须能在 `defaultCfg`（或 `defaultCfg.storage`）里找到」——提取出错会立刻失败。

## 2. 本批交付

| 项 | 说明 |
| --- | --- |
| 子页框架 | 设定分页顶部 V1 同款子标签（`.ftt-subtab`，当前页 `ftt-on`）+ 「设定 · <页名>（N 个配置项 / 共 105 项 14 页）」标题行 |
| 全部配置控件 | 105 项全部可渲染与写回：开关用 V1 结构 `.ftt-switch + .ftt-slider`（附「已开启 / 已关闭」），文本/数字用 `input`，下拉用 `select`，正文域用 `textarea`；缺失键显示「（未定义）」 |
| 写回唯一入口 | `applySettingsControl(key, raw)`：普通键写 `cfg[key]`、`storage.` 前缀写 `cfg.storage[k]`、`a.b` 写嵌套对象 → 随后 `saveKernelCfg()` 持久化到 ST 配置；失败只回报不抛 |
| 数据管理页动作 | **导出 JSON**（`exportStateJson()`：格式 `ftt-memory-v2-export` + 版本/作用域/时间戳 + state；结果进文本框并尝试写剪贴板）、**导入 JSON**（`importStateJson()`：接受导出的信封或裸 state，**按 id append-only 合并，同 id 以当前为准，绝不删除现有数据**）、**清除已处理记录**（复用 B3 的 `clearFloors`） |
| 关于页 | 版本 / 模块名 / 内核配置键数 / 默认配置键数 + 对齐进度指引 |
| V2 附加设定块 | V1 无、V2 有的能力保留：启动自动检查更新、更新检查仓库、检查更新、**V1 数据导入（干跑/写入）**、14 维启用勾选（避免被 V1 页面替换掉） |
| 待后续批次（页内明确标注，**不放假实现**） | 提示词模板分组编辑/恢复默认/签名迁移（B6）；存储探测/测试/同步动作（B7）；内容弱化的词条库与规则库编辑（B8）；调试日志与缓存清理（B9）；API 页（V2 走宿主连接，已在页内说明） |

## 3. 测试（`tests/unit/settings-pages.test.js`，6 项）

- **P1** 子页与 V1 同名同序（14 组 id:label 逐字比对）+ 子标签高亮
- **P2** 控件总数 105 与逐页数量（12/12/3/18/25/12/5/5/13）
- **P3** **全部控件键可解析**（普通键在 `defaultCfg`、`storage.*` 在 `defaultCfg.storage`）——提取零漏配
- **P4** 渲染结构（开关 `.ftt-switch` + 已开启/已关闭；文本 input；下拉 select；面板内出现子标签条）
- **P5** 写回（含 `storage.*` 嵌套）→ 内核 `cfg` 与 ST 配置容器同时更新；空键安全失败
- **P6** 面板接线：`settingsSub` 切页、数据管理页含导出/导入/清台账按钮、导出走钩子并记录字符数、导入调用钩子

门禁：单元 **26 文件 / 337 断言**、冒烟 **55 项**、五道门禁全绿。
