- `phase='loading'`（首屏载入中）→ 各分页只渲染 `ui/panel.js#loadGateHtml()`：「⏳ 正在读取数据…（已等待 N 秒）」+「暂不展示内容、也不执行任何动作」；
  标题栏把「总记忆数」换成 `⏳ 读取中…` 胶囊（此刻计数必为 0，会误导）；抽屉卡片 `statusBlockText()` 同样只报读取态；
  动作除「关闭 / 切页」外一律拒绝（`ok:false, reason:'loading'`）**且不触达任何钩子**；
- 载入结束 → `index.js` 设 `phase='ready'` 并**自动重绘**已打开的面板与抽屉卡片；载入**失败**也放行（`phase='failed'`，绝不把用户永久挡在门外）；
- **超时兜底** `LOAD_GATE_MAX_MS = 20s`：宿主读取 API 挂起时自动放行并留痕 `timeout:true`（界面不被永久拦住）；
- 默认 `phase='idle'`（未开始过载入）**不拦截** —— 保持既有行为与外部接口口径不变；`teardown()` 复位为 `idle`。
