# P10p · 总览精简：管线状态行 + 中断按钮条件展示 + 移除越位入口（v2.52.0）

> 文档版本：v1.0 ｜ 日期：2026-09-26 ｜ 状态：生效（v2.52.0）
> 触发（用户要求）：「总览的**管道提示信息缺失**；总览的**停止按钮是有条件展示**，不是始终出现；
> 总览的**提示信息太多**，很多都是历史遗留产物，请**言简意赅**处理；总览的**清理已处理记录按钮不应该出现**，
> 该设计是**设定数据管理**中的内容。」

---

## 1. 改动（`ui/panel.js#overviewBody()` 重写）

| # | 要求 | 落地 |
| --- | --- | --- |
| ① | 管线提示缺失 | 新增 **`🧵 管线状态` 行**（v2.63.0 起标记改为 V1 同名 `data-ftt-pipeline-label`，并按 V1 v1.85 的 500ms 心跳动态读秒 —— 见 `docs/P10aa`）：进行中 → `正在分析记忆（AI 摘要）· 分段 x/y · 第 a-b 楼 · 已用时 Ns[ · 已请求中断]`；空闲 → `空闲`。数据来自新接线钩子 `hooks.busy()`（`extractBusy()`）与既有 `hooks.batchProgress()`；读秒起点由面板侧 `busySince` 记录（v2.63.0 起优先取 `batchProgress().since`） |
| ② | 停止按钮不该始终出现 | `✖ 中断`（`abortAnalysis`）**只在 `busy === true` 时渲染**；空闲时 DOM 中不存在（动作入口仍保留，供命令/脚本调用） |
| ③ | 提示太多、历史遗留 | 精简为 5 段：时钟区 → 管线状态行 → 一行注入概览（`🧷 注入 N 字 · 命中/未命中 · 预算`）→ 工具行 → 一行类目胶囊（`📚 共 N 条` + 各维度徽标）+ 未摘要楼层按钮 + 一行「已处理 N 楼」。**删除**：已处理区间长清单（`已处理区间：0-1、3`）、「『提取记忆』= …」长说明、NSFW 长状态段落（改为按钮内候选计数 + `FTT.nsfwState()` 可读）、重复的标题层级 |
| ④ | 清理已处理记录越位 | 总览**不再渲染** `data-ftt-action="clearFloors"`；该动作仅保留在 **设定 → 数据管理**（`ui/settings-pages.js#pageExtraHtml('data')`），钩子 `hooks.clearFloors` 不变 |
