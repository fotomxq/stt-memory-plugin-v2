## 1. 目标 / 非目标

### 1.1 目标

1. 把数据维度缺陷按**风险从高到低**排成可实施序列（§4），并给出每条的可测验收与回退（§8）；

3. 把「不进哈希的字段」在合并时的口径补齐到可测（§3.3）；
4. 登记三项新发现并给出处置（§0 摘要、§3.6）。

### 1.2 非目标（明确不做）

- N1 **不改任何代码 / 不动版本号 / 不打 tag**（设计轮次，`开发守则.md` §1）；

- N3 **不调整各维存储上限**（实测各维占用率仅 4%–10%，不是瓶颈；`D16` §6）；
- N4 **不动跨端同步语义**（`D11` 口径不变；`D16` §6）；
- N5 **不改 `uses` 的累加口径与时机**、不改 AI 提取流程与提示词结构、不新增容器（`D7` §2 N1–N6）；
- N6 **不在文档 / 日志里记录任何正文与角色名**（`scripts/check-local-leak.js` 继续把关）。
