# P10r · 数据管理页重排：导出/导入 UI、快照只出统计、本地缓冲统计修正（v2.54.0）

> 文档版本：v1.0 ｜ 日期：2026-09-26 ｜ 状态：生效（v2.54.0）
> 触发（用户要求）：「（数据管理）**快照/缓存管理错误**，请核对**该内容的一致性**、展示信息**仅为统计信息，
> 而不是具体明细**；下面的**导入和导出 UI 设计有问题**，请完善；**提示信息过于罗嗦，完全没告清楚用户这是什么、
> 使用有什么后果**，请修复。」

---

## 1. 发现的三个真实缺陷（先核对，再改）

| # | 缺陷 | 证据 |
| --- | --- | --- |
| ① | 数据管理页「本地缓冲」的调试日志条数**永远是 0** | 代码读了不存在的字段 `logs.count`，而 `debugLogStats()` 返回的是 `{n, cap, kinds, newestAt}` |
| ② | 「交互追踪简报」条数是**内存事件数**，不是已持久化的简报数 | 用了 `traceStats().total`（会话内存事件，上限另有一套），而实际持久化的是 `SPreset_FTTMemoryTrace` 里最近 120 条简报 |
| ③ | 「清空时间线」只清内存，持久简报仍在 → 调试页 0 条、数据管理 N 条 | `core/trace.js#traceClear()` 未调用 `hooks.save([])` |

同时按用户要求处理「具体明细」与「啰嗦提示」：快照链区块此前铺开每条快照的 id / hash / 基线 + 三个按钮。

## 2. 改动

| # | 要求 | 落地 |
| --- | --- | --- |
| ① | 只展示统计 | `ui/snapshots.js#snapshotStatText()`：`共 N 条（根 r · 增量 i）· 可还原原子 c 条 · 删除台账 d 条 · 占用 ~B · 上限 30`；数字全部来自 `snapshotSummary()`（现算 `state.snapStore`，与明细同源）。逐条明细移入默认收起的 `<details data-ftt-snap-details>「🔧 高级：快照明细与还原」`（折叠时仍可从统计行看全貌） |
| ② | 统计数字一致 | `ui/buffer-manage.js#bufferStats()` 单一来源：版本清单缓存 `fttAboutJson` / 调试日志 `SPreset_FTTMemoryDebug` / 简报 `SPreset_FTTMemoryTrace`；条数取真实持久层，字节取原始串 UTF-8 字节（`[]`/`{}`/空 计 0），附上限与「最近时间」；`rawBytes()` / `byteLen()` / `fmtBytes()` 可测 |
| ③ | 缓冲可清理 | 三类缓冲各自一个 `🧹 清除`（`aboutClearCache` / `dbgClear` / `dbgTraceClear`），无数据时 `disabled`；`core/trace.js#traceClear()` 同时 `hooks.save([])`，顺手补齐「清空时间线」的持久层一致性 |
| ④ | 导出/导入 UI | 数据管理页改为五个分块：📤 导出备份 / 📥 导入存档（合并）/ ⚠️ 删除数据（不可恢复）/ 🧬 快照链 / 🗂 本地缓冲；粘贴框与「⬆ 导入粘贴内容」相邻；导出结果文本框只在数据管理页渲染（`ui/panel.js#settingsBody`） |
| ⑤ | 提示言简意赅且讲清后果 | 每块最多两句，含「不会删除 / 不可恢复 / 建议先导出备份」等后果；删除 `localStorage`、相对路径候选、缓存 TTL 等实现细节 |

## 3. 界面结构（数据管理页）

```text
📤 导出备份        一句话用途 + [⬇ 导出 JSON 文件]
📥 导入存档（合并） 合并规则与「不会删除」 + [⬆ 选择文件导入] + 粘贴框 + [⬆ 导入粘贴内容]
⚠️ 删除数据（不可恢复）
                   [🧹 清除已处理楼层记录] [🗑 清空当前角色记忆] + 两条后果说明
🧬 快照链（自动备份） 统计行 + [📸 立即建根快照] [🧹 整理快照链] [🗑 清空快照]
                   └ 🔧 高级：快照明细与还原（默认折叠）
🗂 本地缓冲        版本清单缓存 / 调试日志 / 交互追踪简报（各带条数·上限·字节·[🧹 清除]）
```

## 5. 未验证 / 风险

1. `<details>` 折叠在酒馆面板内的样式依赖新增 CSS（`.ftt-details`，`style.css`）；真实浏览器下的观感未实测（本机无运行时）。
2. 「动作自身也会被追踪」：点「🧹 清除」清空简报后，日志里通常会立刻出现 1 条该动作的简报（这是真实行为，
   测试按「≤1 条且旧简报消失」断言，而不是假的 0 条）。
3. 快照明细折叠后仍是唯一还原入口（无二级页面）；若后续要彻底移出数据管理页，需另开「快照页」。
