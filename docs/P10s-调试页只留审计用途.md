# P10s · 调试页只留审计用途：看日志 / 导出日志 / 清空（v2.55.0）

> 文档版本：v1.0 ｜ 日期：2026-09-26 ｜ 状态：生效（v2.55.0）
> 触发（用户要求）：「调试页面有大量无关提醒，尤其是**涉及到具体开发的内容、历史内容**完全没必要展示，
> 该页面核心目标就是方便**查看审计日志、导出日志**等操作。」

---

## 1. 调试页保留什么、删掉什么

| 区块 | 保留 | 删除 |
| --- | --- | --- |
| 记录开关 | 开关 + 「关闭后不再记录新日志；已存日志仍可查看。」 | 无（这一句是后果，有用） |
| 📋 日志 | 清空按钮 + `共 N 条 · 总占用 X（最多 300 条 · 最新在上 · 点击展开）` + 按类别计数 + 逐条可展开详情 | 标题里的「（上一轮请求的关键词 / 向量提取 / 发送记忆 / 请求日志）」实现枚举；空态里的「运行「AI 摘要」或「自动修复」后在此显示」 |
| 📦 导出调试包 | 按钮 + `共 N 条日志 · 异常 E 条` + 导出文本域 | 「版本 / 时间 / 作用域 / 宿主环境与能力探针 + 一键诊断快照（运行态、探针缺失项）+ 全部调试日志（含「异常」类：未处理的 Promise 拒绝、脚本错误、面板动作失败）」长说明 → 缩为「包含全部日志与运行态诊断，不含记忆正文；导出后可直接贴给维护者排查。」 |
| ⚠ 异常捕捉 | `共 N 条` + 最近一条（含代码站点）+ 最近 3 条 | 标题括注「（host 全局 error / unhandledrejection + 面板动作失败）」；空态不再渲染空的「最近 3 条：」行 |
| 🧭 交互与宿主调用时间线 | 类别筛选（带计数）+ `会话 X · 事件 N（上限 C）· 级别 L` + 逐条（opId / 耗时 / 结果 / 代码站点 / 异常的上下文窗口） | 标题括注「（点击 → opId → 底层调用 → 结果 → 代码位置）」；「记录：用户交互（点击/变更/切页）· 宿主 API 调用 · 命令与 FTT 入口 · 落盘/注入 · AI 调用 · 异常」；「本机另存最近 120 条简报（设定 → 数据管理 → 本地缓冲…）」；footer 的「纯内存环形缓冲 + 导出包可直接贴给维护者」长句 → 「仅内存，重启即空」 |
| 🕒 时钟取值追踪 | 「取值口径：**值 ← 来源**；同时列出未采用的候选与本次落盘结果。」+ 两节 + 清空 | 「来源中文名取自 `core/clock-trace.js` 的全量登记表，共 N 项」；「排障时先跑一次提取/巡检再回本页查看」（且「巡检」功能已在 v2.51.0 移除） |

**页序**（按用途）：记录开关 → 📋 日志 → 📦 导出调试包 → ⚠ 异常捕捉 → 🧭 时间线 → 🕒 时钟取值追踪。
「导出」与「日志」相邻，符合本页的核心目标。

## 2. 顺带清理的同类噪声（其它设定页）

- `ui/panel.js` 设定页标题行：`设定 · X（N 个配置项 · 共 M 项 / 13 页，结构与 V1 同名同序）` → **`设定 · X`**。
  这是每页顶部都会出现的开发与沿革说明，属同一类「没必要展示」的内容。
- `ui/settings-pages.js`：删除 `PENDING_NOTE` —— 提示词页 / 存储页各有一条
  「…在 B6 批次接入；本页先提供…」「…依赖 B7 批次的内核；本页先提供…」的历史待办说明（这两个批次早已交付）。

## 4. 未验证 / 风险

1. 审计用的**代码站点（file:line）保留**在时间线与异常条目里 —— 它属于定位证据，不是开发说明；若您认为也不该出现，可再降级为仅显示文件名。
