# FTT记忆组件 V2（SillyTavern 原生扩展）

给长篇角色扮演用的**长期记忆扩展**：自动把剧情沉淀成结构化记忆，在每次生成前按预算注入回上下文，让角色记得住、不穿帮。

> 形态：标准 SillyTavern 第三方扩展（**源码即发布物**：无构建、无依赖）。
> 与 V1（酒馆助手 iframe 脚本）**不可同时启用**（两者都会注入记忆，同开会重复注入）。
> 版本历史见 `CHANGELOG.md`；完整文档见 [`docs/README.md`](docs/README.md)。

---

## 1. 它做什么

| 能力 | 说明 |
| --- | --- |
| **自动提取** | 生成后读取新楼层，交 AI 提炼增量 JSON 并落库（情节 / 状态 / 角色 / 记忆 / 物品 / 货币 / 计划 / 悬念 / 场景 / 概念 / 平行事件 / 传言 …） |
| **按预算注入** | 生成前组装记忆正文写入提示词；**永不中断生成、不改聊天内容**，失败静默 |
| **知情约束** | 机械生成「谁知道什么」的硬约束段；未列出的角色一律按不知情处理 |
| **修复与维护** | 各维度一键修复、去重融合、清理孤儿关联 |
| **遗忘与演化** | 按**剧情时间**（非现实时间）老化衰退；传言演化、平行事件推演与转正 |
| **剧情时钟** | 只以最新情节为可信来源，绝不使用现实日期 |
| **备份与迁移** | 导出 / 导入、快照链、跨端同步、旧版（V1）数据导入 |

## 2. 安装

1. **ST 界面安装**：扩展 → 安装扩展 → 填仓库地址 `https://github.com/fotomxq/stt-memory-plugin-v2`（分支 `main`，也可指定标签）；
2. **手动安装**：把本目录放到 `SillyTavern/data/<user>/extensions/stt-memory-plugin-v2/`；
3. 在扩展列表启用「FTT记忆组件 V2」即可，**无需任何构建步骤**。

## 3. 使用

| 入口 | 打开 |
| --- | --- |
| 扩展魔杖菜单「FTT记忆组件」 | 主面板（总览 / 情节 / 状态 / 角色 / 记忆 / 物品 / 货币 / 传言 / 计划悬念 / 场景 / 概念 / 平行 / 设置） |
| `/ftt-ui [分页]` | 同一面板，可指定分页 |
| 右下角悬浮「FTT」按钮 | 兜底入口（主入口不可用时出现） |
| 扩展设置抽屉 | 面板设置（默认关闭，可在设置里打开） |

日常开箱即用：打开聊天载入本角色记忆，生成前注入、生成后自动提取；需要干预时在面板里查看 / 编辑 / 删除条目，
或触发修复、演化、推演、导出。

**找不到面板？** 用 `/ftt` 或 `/ftt-panel` 自查，详见 [`docs/排障-面板不显示.md`](docs/排障-面板不显示.md)。

## 4. 命令与宏

| 入口 | 说明 |
| --- | --- |
| `/ftt` | 状态：版本 / 宿主连接 / 能力探测 / 事件绑定 / 入口诊断 |
| `/ftt-ui [分页]` | 打开面板 |
| `/ftt-analyze [楼号\|list]` | 手动提取记忆 |
| `/ftt-import [apply]` | 导入旧版（V1）数据（干跑 / 写入，不删源） |
| `/ftt-panel` | 面板排障 |
| `{{fttVersion}}` / `{{fttStatus}}` | 宏 |
| 控制台 `FTT` | 只读调试导出（快照 / 探针 / 追踪 / 调试包） |

## 5. 更新

- 首次启动自动检查一次，之后按间隔（默认 24 小时）自动检查；设置内可手动检查；
- 「立即更新」由你点击后调用酒馆原生更新端点执行；
- 扩展**不下载、不写入、不执行**远端代码；失败一律静默，不影响聊天与生成。
